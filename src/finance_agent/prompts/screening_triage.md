# 判据
- 重大风险事件（如被证监会立案调查、大额减持、业绩预亏/暴雷等）→ drop，reason 必须点明风险事实；
- 无风险事件，或事件与公司经营基本面无关 → keep；
- 证据不足时倾向 keep（宁可多留不可错杀）。
