## 4. MDE 与阈值换算依据【2026-09-17 按功效反算锁定，替换草案值】

**换算工具**：`aggregate.py::mde_paired_binary`（配对二值 / McNemar 口径）：
`δ_MDE = (z_{α/2} + z_β)·√(ψ/n)`，α=0.05 / power=0.8；ψ = 两态判定不一致率（未知取 0.5 最大方差、保守）；
两条下界约束 δ≤1 且 δ²≤ψ，违反即返回 `None` = **该样本量下无分辨率**（不得用一个小数字假装能测）。

| 有效配对单元 n | MDE（ψ=0.5） | MDE（ψ=0.2） |
|---|---|---|
| 5 | **无分辨率（None）** | 无分辨率（None） |
| 10 | 62.6pp | 39.6pp |
| 15 | 51.1pp | 32.3pp |
| 20 | 44.3pp | 28.0pp |
| 40 | 31.3pp | 19.8pp |

**按此锁定（替换草案值）**：

- **B1/B2/B5**（分母 = 全标的，n=20）：**MDE = 44pp @ ψ=0.5**（ψ=0.3 → 34pp；ψ=0.2 → 28pp）。
  草案值 10pp **不成立**，作废；正式开跑后以实测不一致率把 ψ 收窄并复算（复算值写入本文件与 `metrics.md`）。
- **B3/B4**（有效分母 = 可执行决策标的，实测暴露率 0.25 → n≈5）：**当前样本量下无分辨率**——
  草案值 20pp 不成立。三条出路（**待 owner 决策**，本条为 P2 开跑的前置阻塞）：
  1. **扩样本**：按 0.25 暴露率，要拿到 n≈20 个可执行决策需 ≈80 标的（成本 ×4）；
  2. **换单元**：以「决策内执行参数逐条出处检查」为单元、按标的聚类（单元数上去，但需实测 ICC
     折算有效 n —— `design_effect`/`effective_n` 已备，n 待材料实测后填）；
  3. **降级为描述性**：B3/B4 只报点估计 + 簇 bootstrap CI，**不作显著性裁决**（在报告中写明
     「该腿无分辨率，仅描述」）。
- **决策阈值**：沿用 P1 口径（机制价值 = 暴露率 × 拦截率）——某编排层组件若其主指标 CI 整体
  **低于**成本阈值，则进入裁剪候选；成本阈值 = 该组件的 token/延迟开销占比（P2 跑批时按 trace
  实测填入，不得先于实测给定）。**注意**：MDE 大（44pp）意味着只有**近乎全或无**的层效应才可能
  被检出——阴性结论须按 §1.7④ 的「分辨率不足」句式写（带 MDE 与扩样方向），不得写「无价值」。

## 5. 停止规则

1. 校准一致率 <0.80 → 该批判定作废、重校准，不进入结论；
2. 阳性对照（已知劣化变体）测不出显著差异 → 本批阴性结论作废；
3. B5 位置偏倚检验（A/B 同分率）异常高 → 暂停并复核盲评材料；
4. 单批 judge 调用预算超申报值 20% → 停机复核，不硬扩样本。
