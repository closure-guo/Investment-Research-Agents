## 4. MDE 与阈值换算依据【2026-09-17 按功效反算锁定，替换草案值】

**换算工具**：`aggregate.py::mde_paired_binary`（配对二值 / McNemar 口径）：
`δ_MDE = (z_{α/2} + z_β)·√(ψ/n)`，α=0.05 / power=0.8；ψ = 两态判定不一致率（未知取 0.5 最大方差、保守）；
两条下界约束 δ≤1 且 δ²≤ψ，违反即返回 `None` = **该样本量下无分辨率**（不得用一个小数字假装能测）。

| 有效配对单元 n | MDE（ψ=0.5） | MDE（ψ=0.2） |
|---|---|---|
| 5 | **无分辨率（None）** | 无分辨率（None） |
| 10 | 62.6pp | 39.6pp |
| 15 | 51.1pp | 32.3pp |
| 20 | 44.3pp | 28.0pp |
| 40 | 31.3pp | 19.8pp |

**按此锁定（替换草案值）**：

- **B1/B2/B5**（分母 = 全标的，n=20）：**MDE = 44pp @ ψ=0.5**（ψ=0.3 → 34pp；ψ=0.2 → 28pp）。
  草案值 10pp **不成立**，作废；正式开跑后以实测不一致率把 ψ 收窄并复算（复算值写入本文件与 `metrics.md`）。
- **B3/B4**（有效分母 = 可执行决策标的，实测暴露率 0.25 → n≈5）：**当前样本量下无分辨率**——
  草案值 20pp 不成立。三条出路（**待 owner 决策**，本条为 P2 开跑的前置阻塞）：
  1. **扩样本**：按 0.25 暴露率，要拿到 n≈20 个可执行决策需 ≈80 标的（成本 ×4）；
  2. **换单元**：以「决策内执行参数逐条出处检查」为单元、按标的聚类（单元数上去，但需实测 ICC
     折算有效 n —— `design_effect`/`effective_n` 已备，n 待材料实测后填）；
  3. **降级为描述性**：B3/B4 只报点估计 + 簇 bootstrap CI，**不作显著性裁决**（在报告中写明
     「该腿无分辨率，仅描述」）。
- **决策阈值**：沿用 P1 口径（机制价值 = 暴露率 × 拦截率）——某编排层组件若其主指标 CI 整体
  **低于**成本阈值，则进入裁剪候选；成本阈值 = 该组件的 token/延迟开销占比（P2 跑批时按 trace
  实测填入，不得先于实测给定）。**注意**：MDE 大（44pp）意味着只有**近乎全或无**的层效应才可能
  被检出——阴性结论须按 §1.7④ 的「分辨率不足」句式写（带 MDE 与扩样方向），不得写「无价值」。

## 5. 停止规则

1. 校准一致率 <0.80 → 该批判定作废、重校准，不进入结论；
2. 阳性对照（已知劣化变体）测不出显著差异 → 本批阴性结论作废；
3. B5 位置偏倚检验（A/B 同分率）异常高 → 暂停并复核盲评材料；
4. 单批 judge 调用预算超申报值 20% → 停机复核，不硬扩样本。

## §9 B5 重跑修正案（2026-09-18，owner 批准）

- **问题**：首批 B5（analysts 对 full）为同义反复口径——analysts 臂无决策章节而判据是
  「更有助于决策」→ 20:0:0 不得读作层价值。
- **修正**：对照臂换 **through_trader**（analysts+辩论+研究经理+Trader，无风控辩论/FM）
  ——两臂都含决策层，唯一差异 = 风控辩论+FM 层；即预登记 §8 预留的「裁掉一层但保留
  Trader」选项（plus_debate 不含 Trader，故不适用）。
- **成本**：材料腿 through_trader × 20 标的（≈13–16 次/标的，合计 ≈300 次，owner 已批）
  + B5 判定 20 对 × K=3 = 60 次。
- **判定与门控**：B5 rubric 与盲评协议不变（A/B 位置随机、K=3 多数决、位置偏倚停止规则③）；
  判定过校准门控（≥0.80）才进结论，采样按协议 v2（正例全审 + 高把握…→ 判定正例分层）。
- **停止规则**：沿用 §0（解析失败 >10%、偏倚异常、超申报 20%）。


## §10 B5 结论级盲评修正案（2026-09-19，owner 定稿判据）

- **动机**：§19.10 的 20:0 被定性为「内容量对照下的方向性读数」——评审理由暴露结构识别
  （数谁多章节）与篇幅偏好，无法度量修改的质量增益。
- **口径**：只比**最终交易指令**（方向/置信度/仓位/触发条件/理由，两臂各约 300–500 字，
  同一 Trader 初稿的修改版 vs 未修改版）。六准则：方向自洽 / 置信度校准 / 可执行性 /
  风险边界 / 可证伪性 / 内部无矛盾。**硬排除**：谨慎不加分、决断不加分、篇幅文风不计、
  流程环节提及不计（防 LLM 评审的谨慎先验 × 风控层系统性偏谨慎的伪 20:0）。
- **tie 语义**：两指令实质等价（风控层原样批准的对，预期 3–4 对）判 tie 为正确行为。
- **暗对照**：混入 2 对同臂对（A=A，评审不可知）→ 应判 tie，抓位置偏差（+6 次）。
- **decisive_criterion**：每票记录起决定作用的准则号，聚合后回答风控层主要提升哪个维度。
- **边界**：测质量增益的方向与维度，不测盈利（B6 外部锚）；rubric 版本 b5c-v1。
- **成本**：先 2 对试跑（6 次）肉眼检查理由是否内容级，后全量 20 对 ×3 + 暗对照 6 次。
- **校准**：≥20% 人工复核（非 tie 优先），一致率 ≥0.80 才进结论。
