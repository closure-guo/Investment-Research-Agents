# P1-A1 确定性指标注入补测预登记

族 A 补测项（登记见 `openspec/changes/BACKLOG.md`「族 A 补测项：A1 / A4 尚无专门单元」）：
A1 的登记主张 =「没有代码算指标，LLM 会自算并算错」；失败模式 = 计算幻觉。

- 主指标: 计算型 claim 数值错误率（可重算根 claim 中 `value_mismatch` 占比），两态配对 Δ = OFF − ON
- MDE: 15pp（先验；10 标的配对、可重算 claim ≈30 条/标的。跑完 pilot 按 `aggregate.py` 簇 bootstrap 实测簇间方差重算并锁定；重算值与先验不符以重算为准，并在 `metrics.md` 时间线记一行）
- 决策阈值: Δ < 5pp 判「确定性指标注入无可见价值」——依据：该机制的成本不是 token（compute 全程离线、零 LLM）而是 state 体积与口径维护面，其收益必须体现在「LLM 自算错误」的减少上；5pp 是「机制有没有作用」的最小可操作差异（低于此，错误率的绝对量级不构成报告级风险，应改走别的加固路径）
- 样本量依据: 10 标的 pilot（复用 P1 同源材料快照，零新增 fetch；每标的 2 趟分析师 = OFF/ON）；若 CI 跨 0 且区间宽 > 2×MDE，扩到 20 标的正式批；推断单元 = 标的（簇 bootstrap B=10,000）
- 停止规则: ①OFF 态 void（compute 输出键缺失 / `compute_metrics` 跑不动）比例 > 30% → 停跑复核材料；②两态 claim 产出量差 > 3 倍 → 先归因「LLM 回避给数」再读错误率（产出坍缩本身是读数，不是噪声）；③累计成本超 400 次 LLM 调用停跑
- rubric 版本: judge-v8 + round7（本批判定全走 code，不判 rubric 维度；列出仅供批次对齐）
- 成本分型: 真跑型（每标的 2 趟分析师；claim 判定走离线链零 LLM，citation 节点的稀疏修复若触发按 meter 归属）
- 阳性对照: OFF 态必须**确实**缺 compute 输出键（`compute_output_keys_absent = []` 为门禁，否则判 void）——两态若非只差这一个变量，本批阴性作废

## 口径说明（读结论前必读）

1. **两态同一把尺子**：OFF/ON 的 claim 判定都用同一份**完整**快照 + 生产 citation 链
   （`pilot_runner.run_citation_chain`，A3 ON）。重算路由（incident 028 修复）保证
   可重算根的 claim 真值来自**原始数据重算**，与派生字典在不在无关——OFF 态的自算值因此
   能被同一判据抓住，不需要第二套口径。
2. **OFF 态 = 分析师 context 不带 compute 输出**（`compute_metrics` 返回键整体剥离，
   原始三表 / kline / 新闻 / 宏观原样保留）。它是「compute 节点缺席」的可复现代理，
   不是「数据缺失」——两条威胁线不同，不得混读。
3. **不是逃逸法**：本批主指标是**错误率差**而非拦截率——A1 没有「拦下」语义，
   它的价值在于「从源头不让错值产生」，故判据是产出 claim 的正确率。
