## 根因

**缺陷 A（校验器误报 bug）**：`_NON_PRICE_KEYWORDS` 缺 `var`。`VaR95` 的 95 前窗无任何关键词命中 → 被提取为股价（量纲护栏全过：95 在 64-6400 数量级带内）→ 对比近期低点 570 报偏差 83.33%。

**缺陷 B（spec 规则粒度）**：空洞形态判定为句法模式——「站稳/站上 X 且 X ≤ 现价 → 条件已满足」。复合条件触发「先回撤/跌破至 X，再站稳 X」是回踩确认结构（价格须先运动，整体前瞻），句法上却命中后半句上破模式。且 `_BREAKDOWN_WORDS` 缺「回撤至/回调至」使前半句方向检测为 None；预扫若做量纲过滤，「回撤」关键词还会误杀「回撤至」的下破方向（实施中发现的第二层坑）。

**LLM 行为评估**：一致、可响应、可辩护——收到反馈后修掉 VaR 表述、强化前置条件说明、显式声明条件未满足。非根因。唯一随机通道是措辞（写不写显式数值决定可检测性）。

## 修复（fix-decision-price-check-false-positives）

1. `_NON_PRICE_KEYWORDS` + `var` / `在险价值`（缺陷 A）
2. `_BREAKDOWN_WORDS` + `回撤至` / `回调至`（缺陷 B1）
3. `_check_snippet` 复合回踩豁免：同条目同数值 down+up 方向共现 → 跳过空洞判定（deviation 不受影响）；预扫不做量纲过滤（缺陷 B2）
4. spec 场景 1 例子更正：原「95 vs 570」例子即误报案例，改为真幻觉形态（「目标价看到 95 元附近」）

回归组：688072 gen1/gen2 触发原文 + VaR95 reasoning 原文 + 三条护栏（单上破仍判空洞 / 真幻觉仍报偏差 / VaR 变体形态不误报）。
