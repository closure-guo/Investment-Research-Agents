# 032: 历史战绩组合指标失真——neutral 幻影空头 + 坏参考价 + 年化口径放大，快照年化 +2853%（2026-09-29）

## 症状

`agent_metrics_daily` 2026-09-28 快照：年化收益 **+2853%**、波动率 **91%**、夏普 **31.3**、最大回撤 6.7%、风险分 **10（极高）**。净值曲线本身看似平静（0.97~0.99），风险卡与曲线量级明显自相矛盾。

**发现渠道**：人工审视历史战绩页数据合理性 → 逐层下钻复算闭环。

## 根因（三缺陷叠加，均经生产库数据核实）

### 根因 A：neutral 观点被按空头符号盯市（`marking.py:115`）

```python
sign = 1.0 if p["direction"] == "long" else -1.0
```

hold/watch 落库为 `direction='neutral'`，盯市取 `-1.0`（空头）；而回避判定引擎 `judgment.py:120` 对 neutral 按 **long 口径**（注释明示）。同一观点两个引擎符号相反。生产库 12 条有盯市观点**全部为 neutral**（150 条 daily_marks）——整条净值线是"系统建议回避的股票的反向损益"（幻影空头）。

### 根因 B：ingest 参考价无交叉校验（`ingest.py`）

600519（贵州茅台）09-05/09-06（周末）创建的 4 条 neutral 观点记录 `entry_price=1800.0`。行情核实：09-01~09-09 qfq 收盘 1290~1330、hfq 序列连续（**排除除权**）——quote 源在周末返回了偏离实际市场约 35% 的坏价，ingest 唯一校验是 `entry <= 0`。同管道 09-08 上午又批量拿不到价（关联 incident 031 同期数据质量问题）。4 条坏价观点的盯市全部变成 `qfq价/1800 - 1 ≈ -27%` 的假深度"回撤"，再经根因 A 反号成 **+26.9%**。

### 根因 C：净值/年化口径缺陷（`metrics.py`）

1. `daily_portfolio_returns` 首盯市日日收益 = 当日 `cum_return`（相对入场参考价）——入场→首盯市的整段漂移（含根因 B 的坏价缺口）全部记为单日组合收益；
2. 年化 `final_nav^(252/n)-1` 的 n 只数有盯市的日期（n=14）；spec「空仓日记 0 收益」对应的 `if rets else 0.0` 是**死分支**（无盯市日期根本不产生序列点）。

**复算闭环**：09-07 首日组合收益 = (3×26.9% + 0.8%)/4 ≈ +20.4%（4 条茅台坏价 neutral 观点等权），agent_cum 终值 1.2069，n=14 → 1.2069^(252/14)−1 = **28.53**，与快照 `annual_return=28.533411` 逐位吻合；波动 91%、夏普 31.36 同源。

### 伴生发现（运维）

daily_marks/equity_curve 停在 09-24，而 metrics 快照 09-25/09-28 仍在写（数值逐位相同 = 无新数据）——16:30 marking 任务无产出、16:35 metrics 任务正常。页面「快照截至 09-28」展示的是 09-24 数据且无陈旧提示。根因需按红线查后端日志 + Langfuse，另行处置（本 incident 仅修 as_of 诚实性）。

## 为什么未被发现

- 净值曲线被首日归一化（÷first_agent）后视觉平静，与风险卡的失真数字分离展示，人工看图不看不一致；
- 胜率/回避正确率走 predictions 状态域（不经 marks），长期显示「样本积累中」，掩盖了 marks 链路整体失真；
- 首批真实结算要到 2026-11 初（T+20），此前无第二数据源交叉验证；
- 无针对「指标量级合理性」的健康检查（年化/夏普超出常识范围无告警）。

## 修复

delta `update-track-record-data-integrity`（OpenSpec，2026-09-29）：

1. neutral 盯市改多头口径（与回避判定同号），组合聚合排除 neutral（根因 A）；
2. ingest quote↔K 线收盘交叉校验（偏离 >30% 降级收盘价 + WARN）+ 盯市侧坏参考价跳过防护（根因 B）；
3. 净值首盯市日贡献 0、入场参考价退出净值计算、交易日历骨架补空仓日、年化 n = 交易日数（根因 C）；
4. `portfolio.as_of` 改为数据日期（伴生发现）；
5. derived 三表全量重建；predictions 不动（append-only）。
