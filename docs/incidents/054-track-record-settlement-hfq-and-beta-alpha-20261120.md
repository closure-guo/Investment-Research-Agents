## 根因 A：结算 hfq 三源回退，东财/腾讯序列收益率失真

`fetch_kline(adjust="hfq")` 走 东财 → 新浪 → 腾讯 回退链。实测三源的 hfq **不是同一个口径**：

- 新浪 hfq = raw × 常数因子（除权日为台阶）：600015 同窗 +10.0323% 与 qfq +10.0324% 逐位一致；
- 腾讯 hfq 的 hfq/raw 比值逐日漂移（600015 两个月 5.18→4.99；600519 7.06→6.84），同窗收益 +5.63% / +14.59%；
- 东财 hfq 同样漂移（600015 比值 4.02→3.86）。

后果：结算 `raw_return` / `excess_return` 与 ±2% 判定带建立在失真收益上。库内 27 条可同窗口对拍行中 **8 条超额差 >1pp、4 条 >2pp，最大 3.17pp**；同一标的的结算入场价在不同批次间出现 24.92 / 41.11 两档（21 只中 14 只倍数不稳定）。当前样本的分类恰好未翻（0/34），但贴边行已到边界（如 600026 stored +0.73% vs 真值 −0.77%）。

## 根因 B：基准缺日被前值填充成 0 收益参与 β/α

`compute_metrics_from_marks` 对 `benchmark_by_date` 缺失日沿用前值（图线不断点），但同一序列也被用于 β/α 回归——缺日被记成 **0% 基准收益**。2026-11-20 的 16:35 指标快照重拉基准时日 K 尚停在 11-19，于是：

- 基准：11-20 收益 = 0（前值填充）
- 组合：11-20 实际 +3.44%（短期空头组合，当日 000852 −4.89%）

该单日 3.44% 全额计入 α。用「基准去掉 11-20」复算得 β −0.266319 / α +0.125960，与库内 −0.266341 / +0.125947 逐位吻合；用完整基准为 −0.363526 / +0.041407。11-12 快照同型。

## 教训

1. **同名复权口径不等于同一序列**：三源 hfq 的复权因子行为不同，跨源混用会让收益率本身失真；结算类取数必须锁定单一可验证源，失败 fail-closed。
2. **前值填充只适合画图**：任何回归/统计消费都不得把「填充值」当观测值；图表连续性与统计有效性是两套口径。
3. **指标审计必须同窗口对拍**：仅看日报表或单一序列无法发现源间差异；本次靠「同标的同窗口 qfq vs hfq vs raw」逐位对拍才定位。
4. **样本极小时，单日异动即全部**：11-20 一天把年化从 2.2% 拉到 33.4%、夏普从 0.15 拉到 1.99——n=32 的组合指标不应作为能力结论。
