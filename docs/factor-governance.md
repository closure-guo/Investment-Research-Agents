# 因子治理决策记录（Factor Governance Decisions）

> 本文件沉淀因子库治理层面的**政策裁决与边界**（准入统计口径、退役阈值、外部输入治理等）。
> 与 `openspec/specs/factor-library/`（行为契约）分工：spec 写「系统必须做什么」，
> 本文件写「我们选择接受什么风险、何时复查、依据什么读数升级」。

---

## D1. 跨批次多重检验：接受残余风险 + 账本监测 + 触发式升级（2026-10-18 裁决）

**背景**：五道闸的显著性控制（闸③置换检验 999 + BH-FDR q=0.1）按**同批次候选数 K**
做多重检验校正；因子库跨批次累积（月批广度/深度、builtin 注册、收割桥、外部导入各
自成批），批次流没有全局校正 → 长期累积的假发现率名义上高于 q=0.1（issue #355）。

**已交付的数据底座**（add-fdr-candidate-ledger，2026-10-18）：
`factor_admission_ledger` 逐候选记录闸③ p 值/同批校正读数与准入结果（`admit_candidates`
单点记账，四入口全覆盖）；只读读数 `scripts/factor_fdr_report.py` 给出库级汇总、
分批明细与**全局 BH 反事实预览**（把全部已验证 p 值作跨批次家族一次校正）。

**裁决：当前接受残余风险，不实施强制全局校正**（即 issue #355 方向 3），依据：

1. **假发现的代价有界**：因子库产出不直接下单——active 因子只进选股综合分；且每个准入
   因子已过闸④（池级增量：与库内 **|IC 相关| ≤ 0.7** 且验证段有 IR 增量）与闸⑤
   （70/30 按日样本外）两道**非统计防线**，它们对多重检验问题独立；退役侧的衰减监控
   （60 日滚动 IC，连续 20 日负且 |ICIR|<0.1 → degraded）给统计噪声因子一个分钟级的
   退出通道。
2. **当前暴露面为零**：因子库为空（真候选尚未出现），任何时点收紧口径都无需清理存量
   ——「先跑数据、后定政策」的切换成本目前最低。
3. **候选流入率低**：每批数十候选且大多数在闸①②④⑤被拒，累计家族增长缓慢；此时引入
   强制全局校正（含存量撤销/复核面）复杂度高于收益。

**复查触发条件**（任一命中即升级评估，触发材料直接用反事实读数）：

- 账本累计**已验证家族 ≥ 100**；或
- 库内 **active 因子 ≥ 10 且累计反事实保持显著率 < 0.5**（全局账本会推翻过半 active）；或
- 出现**首例「事后被证伪的 active 因子」**（衰减退役且归因=统计噪声而非数据/工程故障）。

**升级候选**（届时二选一，按账本数据裁决）：方向 2「批内折算」——按年度 FDR 预算
把批内 q' 收紧（实现最小）；或在线 FDR（LORD / SAFFRON 族，流式正确控制，实现与验证
成本高）。**监测职责**：每次产生新批次的运行（月批/收割日批）后跑一次
`uv run python scripts/factor_fdr_report.py`（或容器内 `docker compose exec -T backend python scripts/factor_fdr_report.py`）留存读数；
读数异常（家族或推翻率跃变）即按触发条件处置。

**边界**（本裁决不覆盖）：闸①-⑤ 各自的既有口径不变；本裁决不构成「全局校正永不实施」
的承诺——触发条件命中即按上方升级候选重新裁决；裁决记录在案，与 spec 主规范
（factor-library「跨批次候选检验账本」）互证。

## D2. 外部输入（RD-Agent 收割桥 / 外部导入）的准入口径

与 LLM 月批**同一五道闸**（不因外部来源放宽或收紧）；拒绝原因码与读数逐条留档于批次
摘要与账本。外部来源的「软择优」不得替代闸口读数（unify-quant-research-architecture
设计稿 D3 结论）。（2026-10-15 既有实践固化，2026-10-18 记入本文件。）

## D4. 闸④组合方向归一化 + 两项口径维持 + 首批因子准入（2026-10-19）

**背景**：复跑暴露 `max_ret_5d`（稳定负向，|ICIR| ≥ 0.3）过闸②③、死闸④。代码级排查结论：
②|ICIR|、③置换、⑤两段同号、生产选股 L2（带符号 IC 权重）、衰减监控（连续负**且**弱才降级）
均正确处理方向，**唯闸④组合是无方向等权平均**——判官模型与生产组合模型错位（L2 本就能
反向使用负方向因子）。修复见 delta `fix-pool-increment-orientation`（PR #409，已 archive）。

**裁决一：闸④按训练段 RankIC 符号定向（已实施）**。组合内各因子（池与候选同规则）以
**训练段**符号定向后等权参与——只用训练段、无验证段泄漏；统计门槛零改动（|ICIR| 0.3 /
BH-FDR q=0.1 / |ρ| 0.7 / ⑤ 两段同号全部原样）。

**裁决二：旧闸④的「验证段 IR>0」单边过滤不恢复（维持）**。该条件实为未声明的正向偏好，
正是误杀镜像因子的机制，不因「噪声安全」而保留副作用。如实登记其代价边界：
闸④单闸通过率不变（蒙特卡洛 M=3000：50.57%→50.23%）；**②→⑤整链**噪声入库率 ≈1.8×
上界（弱闸③、K=1 压力测试；生产批次 BH-FDR 严格得多）。**若未来观察到噪声入库偏多，
走闸②门槛复核（`docs/evals/2026-10-17-闸②门槛复审.md` 同一条独立决策线）显式收紧**，
不得以恢复④的副作用代替。

**裁决三：自由参数上限维持 3**。`obv5`/`pos20` 等恰差 1 个参数且同族读数 0.27+，
仍不放松——自由参数是过拟合轴。若未来确要覆盖这批候选，优先评估**不增加拟合自由度的
表达形态**（如具名派生指标/宏），而非抬上限。

**附记（与 D1 的交互）**：本日完成**首批因子准入**——`volratio20`/`volcv20`/`range1`
（闸④方向归一化后，生产重放第三轮复现同一结果；库内 3 条 active，事件史 `ADMITTED`）。
**D1 的论据②「暴露面为零（库空）」自此不再成立**；D1 三条复查触发条件均未命中
（累计家族 3/100；active 3/10；无被证伪退役），D1 裁决维持，但其**监测职责自此生效**：
每次新批次后跑 `scripts/factor_fdr_report.py` 留存读数，读数跃变即按 D1 触发条件处置。
