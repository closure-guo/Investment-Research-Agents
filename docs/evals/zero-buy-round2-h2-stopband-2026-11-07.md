## 4. 机制取证（逐层）

- **Trader（watch）**：方向偏多但「不具备执行条件」——入场时点（仅 MA20 上方 2.62%）+ capex/折旧为 0 红灯与应收周转缺失「等待验证」+ 引用风控的止损诊断。注意：同样的基本面瑕疵在 v4 被判「非硬否决」——trader 的等待倾向随止损可用性联动。
- **激进方（关键提案）**：诊断「减仓触发 MA20≈17.21 距现价 2.5% < 单日 VaR 2.79% → **触发落在噪声带内，退出将由随机波动而非趋势决定**」→ 提案「**现价 1/3 试仓，止损放 MA60 一侧避开噪声**，待 Q1 数据验证再加」。
- **保守方（拒绝放宽）**：「把止损从现价下方 2.5% 移到 MA60（约 7.6%）＝单笔最大亏损放大约 3 倍——不是避开噪声，是**把噪声风险换成尾部风险**」；提「收盘确认+波动率缓冲+缩仓三件套」但反对任何试仓。
- **中性方（正确答案其实已出现）**：「缓冲取 2 倍日波动 ≈3.8%（对应约 17.0）……缓冲放宽容忍度只能靠**缩小仓位**换取」——这与 v4 已被接受的 2.5σ 止损同一量级。
- **裁决层**：接受噪声带诊断、拒绝 MA60 放宽、要求「收盘确认+连续两日确认」、写明「**仓位应按单笔风险预算反推，而非按信心分配**」——然后 watch。
