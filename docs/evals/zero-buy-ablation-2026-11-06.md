## 4. 与计划的偏差

1. **判据表第三格的语义修正**：计划把「两臂都 0 buy」解释为「规则不是唯一原因」，
   隐含假设改 trader+risk_judge 可解除全部规则锁。代码事实是该锁有 ≥4 处独立来源，
   两臂删除不足以解除——「两臂都 0」在本实验设计下**不可区分**「锁在未覆盖处」与
   「锁是模型内在偏见」。这是一个需要修正设计后再跑的消融，不是可下结论的阴性结果。
2. **双臂并行**（原计划顺序）：两臂同刻拉同一行情快照，消除数据窗口漂移混杂。
3. **样本替换**（§2）与「本日」=10-30 批次（§2）。
4. **运行器加固**（均为基础设施，不触及实验变量）：`--variant` 可重复（B 臂需双变体）、
   仓库根 sys.path 引导、符号级重试（文件锁窗口 + provider 过载兜底）。

## 6. 建议（第二轮消融设计，待 owner 拍板）

1. **扩覆盖重跑 B'**：在 B 变体基础上叠加 ① fund_manager 无契约变体 ② 4 分析师
   去掉「决策层按 T+20 考核」括注（保留 horizon_hint 字段本身——它有结算价值）。
   若 B' 出现 buy → 锁在这些条款；若 B' 仍 0 buy → 转向「模型内在保守偏见」归因
   （换模型对照或上下文消融）。
2. **时间窗**：选 provider 低负载时段（本次 01:36-03:15 全成，03:32 起过载），并把
   运行器重试参数带入（已就绪）。
3. **不改生产提示词**：在第二轮消融出结论前，trader/risk_judge/fund_manager 的
   生产文本一字不动（本次实验已证明单删两处无效且可能引入新的行为漂移——B 臂
   600026 watch→sell 的升级未见对应证据增量之外的收益）。
