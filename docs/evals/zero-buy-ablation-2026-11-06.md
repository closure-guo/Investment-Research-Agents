## 4. 与计划的偏差

1. **判据表第三格的语义修正**：计划把「两臂都 0 buy」解释为「规则不是唯一原因」，
   隐含假设改 trader+risk_judge 可解除全部规则锁。代码事实是该锁有 ≥4 处独立来源，
   两臂删除不足以解除——「两臂都 0」在本实验设计下**不可区分**「锁在未覆盖处」与
   「锁是模型内在偏见」。这是一个需要修正设计后再跑的消融，不是可下结论的阴性结果。
2. **双臂并行**（原计划顺序）：两臂同刻拉同一行情快照，消除数据窗口漂移混杂。
3. **样本替换**（§2）与「本日」=10-30 批次（§2）。
4. **运行器加固**（均为基础设施，不触及实验变量）：`--variant` 可重复（B 臂需双变体）、
   仓库根 sys.path 引导、符号级重试（文件锁窗口 + provider 过载兜底）。

## 5.1 事后走势核验（owner 复盘质询补充，2026-11-06）

**质询**：样本是否为「事后确认上涨」的票？答：**不是**——样本按「RM 当时意图」选
（4 看多 + 4 看空），非事后收益。10-30 收盘 → 11-05 收盘实测（基准沪深300 +3.21%）：

| symbol | 基线动作 | 区间涨跌 | 超额 | 定性 |
|---|---|---|---|---|
| 300033 | watch | +9.53% | +6.32% | 系统错过 |
| 601066 | watch | +5.15% | +1.94% | 系统错过 |
| 000428 | **sell** | **+15.41%** | **+12.20%** | 看错方向（含 11-05 单日 +10.09%） |
| 600916 | **sell** | +5.08% | +1.87% | 看错方向 |
| 600026 | watch | -5.43% | -8.64% | watch 正确 |
| 002916 | sell | -7.30% | -10.51% | sell 正确 |
| 002648 | watch | -0.91% | -4.12% | watch 勉强正确 |
| 600015 | watch | +1.88% | -1.33% | watch 勉强正确 |

**对结论的影响**：

1. **不推翻、反而补强**：4 只事后上涨票上，A 臂（拆规则后）全部未买——000428 前一
   日 +10% 的信息已在 A 臂输入数据里，仍给 sell（entry 3.82 / target 3.51）；B 臂完成
   的 4 只中 3 只是上涨票（300033/601066/600916），0 buy 复现。
2. **如实记录两处限定**：① 涨后不买可辩解为「不追高」纪律（000428 +15% 后尤甚），
   最干净的错过证据在**基线时点**（10-30 四只上涨票尚未涨即被判 watch/sell），与诊断
   台账「60 条看空胜率 12%」同构；② 8 只样本中 4 只事后下跌，「不买」对它们是正确
   行为——单看全样本 0 buy 无法区分「锁死」与「票本来就不该买」。
3. **设计修正（采纳质询）**：第二轮消融（§6 B' 臂）选样规则改为**事后超额收益**——
   以 10-30 批次中事后超额为正的 4 只（300033/601066/000428/600916）为核心样本，
   不足 8 只再补 RM 看多且事后上涨的票。此改动使「B' 仍 0 buy」能干净归因于锁。
