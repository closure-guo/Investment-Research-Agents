## 4. 归因纯度：严格版没锁住止损距离

**设计意图**：只降 RSI，保留「最近 10 日低点 −1.9%」（≈上次 −2.1% 止损位），让窄止损条件原样保留。

**实际发生**：交易员这次把止损锚在「横盘区下沿 + MA60 止损带」16.80（−4.87%），没有锚在 −1.9% 的近端低点。原因是尾部形态从 v3.1 的「急跌 → 急修复」变成 v4 的「急跌 → 修复 → 7 日横盘微跌」，价格结构里多出一个更宽的平台，交易员的止损锚随之从近端结构外移到平台下沿。

**后果**：这次 `buy` 同时包含两个变化——RSI 降温 **和** 止损距离变宽（1.1σ → 2.5σ）。不能把结果归因为「超买是唯一主因」。但可以确定两件事：

1. **B' 链在零提示词改动下能完整买入**——只要入场不在高位、止损不落在噪声带。提示词层不再有残余锁能单独阻止 buy（v3.1 里的唯一阻塞链在 v4 全部让路）。
2. **止损结构否决不是独立缺陷，而是「高位入场」的下游症状**：价格贴年高 → 最近支撑只有 1.5% → 止损 1.1σ → 风控否决 → 没有「放宽止损/降仓重来」的路径 → watch。两个假设在上游是同一条因果链。

## 5. 对 P1 的影响（优先级重排）

1. **入场时点 / 价格结构纪律（升为第一）**：允许「回踩/横盘后入场」与「动量/突破入场」并存；不得因为「贴近年高」或「止损 < 1.5σ」就直接落 watch；窄止损时先降仓位 / 放宽止损，而不是否决方向。这与 P0 报告 §3 记录的「系统只接受回踩支撑型入场、对动量型入场系统性回避」的结构性偏差一致——真空期上涨的股票常是动量型，这正是零买入的结构成因。
2. **止损协商回路（保留，降为第二）**：真正的窄止损场景仍需要「放宽止损 / 降仓重建仓」的正向重写路径；本轮证明它不是零买入的主因，但它是同一条因果链上的必要保险。
3. **置信度去锚定（不变）**：本次 final confidence 仍是 0.5、trader 0.55、RM 0.58——买是买出来了，但置信度仍扎堆中段（与 metrics.md 待决策 #4 的存量债务一致）。
4. **四态 schema（不变）**：数据缺口模型自发按「中性、压置信、不反向看空」处理，行为已对齐；输出层仍无 `INSUFFICIENT_DATA` 态。

## 6. 方法学教训（下一轮怎么做得更干净）

- 合成 fixture 里「改尾部形态」同时改了两类东西：**动量指标**（RSI/J）和**结构锚**（最近支撑/止损位）。要单独锁住止损距离，必须同时钉住「最近波段低点」和「交易员会选的止损锚」，但后者是模型的内生选择，不能直接固定。
- 更干净的 H2 直接测试（可选，≈10 万 tokens）：构造「RSI 60 左右 + 最后 8 日窄幅震荡（最近低点 −1.2%）」的强趋势案例——此时任何自然止损都 ≤1.5σ。若 B' 仍 buy（风控按 B' 条款降仓/放宽止损），H2 被证伪；若 watch，H2 坐实。这比再改一次尾部更能分离变量。
- 或者直接在 `risk_judge` 变体里加「窄止损 → 必须产出放宽止损/降仓的重写请求」契约，做单变量消融。
