# 研报（卖方研究）驱动分析管线：生态调研与验证成果盘点（2026-10-17）

> **起因**：宏观研报接入管线设计讨论（样例：UBS China Equity Strategy, 2026-09-30）——规划「研报获取 → LLM 结构化提取市场立场/行业偏好 → 有界微调选股排名权重与 Agent 上下文」，需先弄清生态里有没有人做过、有没有已被验证的成果。
> **性质**：外部生态调研（非本仓库实验报告），不进结论注册表；数字均转引自原始来源并标注证据等级。
> **证据等级**：[同行评审] = 有评审 + 样本外/被复核；[预印本] = arXiv/SSRN 自报，无独立复现；[自称] = 仓库/厂商宣称，无第三方验证；[反证] = 被独立评测或社区证伪。
> **方法**：三路并行检索（开源工程 / 学术文献 / 产业实践），英文+中文双线（GitHub API 代码级检索、arXiv/OpenAlex/Crossref、券商金工与财经媒体）。检索日期 2026-10-17。

---

## TL;DR

1. **「研报观点 → 调整权重」闭环：公开世界零先例。** 三路检索一致——没有找到任何项目/论文/产品把卖方研报观点结构化后**有界地调整因子权重或组合权重并披露验证**。最接近的是四个碎片（见 §1），全部止步于「研报→新因子」或「研报→LLM 上下文」。
2. **被验证的成果集中在相邻两段**：①「分析师结构化数据 → 个股因子」（30 年同行评审 + 券商金工产品化，年化超额双位数，但衰减快）；②「LLM 读文本 → 信号」（唯一顶刊验证：Lopez-Lira & Tang, JFE 2026；且效应随 LLM 普及而衰减）。
3. **「宏观/卖方观点 → 组合权重」这一具体方向：设计合理、验证为空。** 存在多篇形态一致的预印本（MacroAllocAgent 等），全部自报回测，零复现。
4. **生态最大的坑是时点污染**：TradingAgents 被自身 issue 区证伪（不可复现 / 前视偏差）、DeepFund 实时评测旗舰 LLM 全部净亏损——「LLM 交易 agent 回测收益」在 2025-2026 被系统性降级为不可采信。
5. **对本项目的启示**：空白 = 差异化机会，但也意味着无先例可抄，须按待检验假设立项（初始先验：无收益证据）；若追求「第一个可信成果」，证据强度排序是 **结构化预期数据（评级/目标价/预期修正）> 研报文本因子 > 宏观叙事观点→权重**。我们设计的确认门禁 / 有界倾斜 / 时点结构 / 披露节恰好逐条规避了生态被批评的雷区（§4）。

## 1. 开源工程：谁在做，验证状态如何

### 1.1 消费研报的项目（全部清单内最接近的四个）

| 项目 | 形态 | 验证状态 |
|---|---|---|
| [microsoft/RD-Agent](https://github.com/microsoft/RD-Agent) `fin_factor_report` | 研报 PDF → 因子假设 → 代码 → Qlib 回测（唯一重量级） | 论文 R&D-Agent-Quant **NeurIPS 2025 接收**（[arXiv:2505.15155](https://arxiv.org/abs/2505.15155)）但评审场景是 `fin_quant`，**report 路径未单独评测**；宣称 "2× ARR" 未复现 [自称]。**本仓库 10-16 实测复现见 §4.1** |
| [HKUDS/Vibe-Trading](https://github.com/HKUDS/Vibe-Trading)（35k stars，活跃） | `get_research_reports` = 东财 reportapi（评级/目标价/EPS 预测）+ 同花顺一致预期 → 挂进多 Agent 投委会工具列表；另有 earnings-revision skill | 研报只进 LLM 上下文，**不进权重**；无回测/实盘验证材料 [自称] |
| [zus12873/llm-factor-platform](https://github.com/zus12873/llm-factor-platform)（1 star） | 卖方研报 → FactorSpec → 歧义必问（不猜）→ 因子库 IC/分位验证——**概念最贴近本项目规划** | 自述 45 PASS / 0 FAIL；1 star、无外部验证 [自称] |
| [Hayden1629/troy-trading-agent](https://github.com/Hayden1629/troy-trading-agent)（0 stars） | 17.6M chunks 授权卖方研报全文索引（FTS5+embedding+RRF）→ 接 Schwab 实盘 + Telegram 审批闸门 | 索引与账户数字均不公开 → **不可独立验证** [自称] |

### 1.2 架构出处与其已证伪状态（重要反面证据）

- **[TauricResearch/TradingAgents](https://github.com/TauricResearch/TradingAgents)**（10 万+ star）：**不消费研报**（代码级检索 `研报`=0）。论文 arXiv:2412.20138 无同行评审；**社区在其自身 issue 区证伪**：[#168](https://github.com/TauricResearch/TradingAgents/issues/168) 不可复现（同区间 -25.44% vs B&H -7.63%）、[#203](https://github.com/TauricResearch/TradingAgents/issues/203) 前视偏差（"每天决策都是 BUY"）、[#483](https://github.com/TauricResearch/TradingAgents/issues/483) `eval_results/` 为空。2026 年仓库自建回测并声明 "results are not guaranteed to match any published figure"。**与 10-05 备忘录结论互证**（docs/evals/2026-10-05-多Agent对单Agent选型调研.md：无单 agent 基线、无消融）。
- [virattt/ai-hedge-fund](https://github.com/virattt/ai-hedge-fund)（64k stars）：README 明示 educational only、**不实际交易**。v2 有 `portfolio/` 规划「blend analyst views into target weights → Black-Litterman」（roadmap，未实现）——**「观点→目标权重」的架构草图可参照，但不是研报** [自称]。
- FinRobot 方向相反（生产研报而非消费）；FinCon 因商业数据未真正开源；StockAgent/AlphaAgent/Alpha-GPT/QuantAgent 均无官方可复现仓库。

### 1.3 结论

生态分两层：**「研报→因子」（有闸门/回测环节）** 与 **「研报→LLM 上下文」（无验证）**；「研报观点→权重调整」闭环为零。另有一条结构性事实：**卖方研报全文有版权**，开源项目普遍只用免费结构化元数据（东财 reportapi / 同花顺一致预期 / akshare），全文语料只出现在闭源项目里。

## 2. 学术：哪些成果经得起验证

### 2.1 已确立（可当作事实引用）

- **分析师评级变动、目标价/盈利预测修正对横截面收益有预测力**——Womack (1996, JF)、Stickel (1995)、Barber et al. (2001, JF)、Jegadeesh et al. (2004, JF)、Loh & Stulz (2011, RFS)、Gleason & Lee (2003, TAR，修正漂移)；综述 AnRFM 2016。效应集中在小盘、低覆盖、利空事件。
- **研报正文文本含超越数字预测的增量信息且市场反应不足**——Huang, Zang, Zheng (2014, The Accounting Review, 500+ 引)。「研报文本值得挖」的学术基石。
- **LLM 文本信号存在性 + 衰减**——Lopez-Lira & Tang，**JFE 2026 正式发表**（DOI 10.1016/j.jfineco.2026.104335，含官方复现包）：知识截止后时点的新闻标题打分显著预测漂移；**收益随 LLM 采用率上升而下降**。
- **LLM 回测前视偏差普遍存在**——Glasserman & Lin (JFDS 2023)；2026 综述（[arXiv:2602.14233](https://arxiv.org/abs/2602.14233)，review 164 篇，任何单一偏差被讨论比例≤28%）。

### 2.2 合理但未验证（预印本/自报，无复现）

- 研报叙事的增量信息：Lv 两篇（[arXiv:2502.20489](https://arxiv.org/abs/2502.20489)、[arXiv:2411.13813](https://arxiv.org/abs/2411.13813)）——把「研报文本→收益」做得最像成品，但只有自报样本外。
- Kim/Muhn/Nikolaev（GPT-4 读财报超越分析师，[arXiv:2407.17866](https://arxiv.org/abs/2407.17866)）：未发表、未复现、**也无直接反驳**——状态是「未验证」而非「被推翻」。
- **宏观/卖方观点 → 组合权重（与本项目规划同构的方向）**：
  - [MacroAllocAgent](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=7286866)（SSRN，2026-08）：五 Agent 读中国宏观沟通文本+市场展望报告 → Black-Litterman 权重，13 个指数 2015-2025，Sharpe 0.955 [预印本/自报]。**这就是我们要做的设计，但零复现。**
  - Narrative-Informed Black-Litterman（SSRN 7588478，财报电话会文本→views）；Top-Down Sector Allocation（[arXiv:2503.09647](https://arxiv.org/abs/2503.09647)，Sharpe 2.51——「整齐得可疑」，与本仓库 AGENTS.md 判别规则同类）。
  - [CN-Buzz2Portfolio](https://arxiv.org/abs/2603.22305)（中国市场 ETF 配置的可复现 benchmark 设计）→ 评测框架参考。
- LLM 挖因子：AlphaAgent (KDD 2025)、Alpha-GPT (EMNLP 2025 demo)、R&D-Agent-Quant (NeurIPS 2025) ——**方法/系统过评审，金融收益全为自报回测**。

### 2.3 被系统性批评（2025-2026）

- **[Alpha Illusion](https://arxiv.org/abs/2605.16895)**（2026）：点名 FinCon/FinMem/TradingAgents/FinAgent/QuantAgent/FLAG-Trader 的「头条 Sharpe」不可作为部署证据。
- **DeepFund**（[arXiv:2505.11065](https://arxiv.org/abs/2505.11065)）"Time Travel is Cheating"：9 个旗舰 LLM（含 DeepSeek-V3、Claude-3.7）**实时**评测全部净亏损；历史回测 = time travel。
- MemTrial（[arXiv:2610.11732](https://arxiv.org/abs/2610.11732)）：LLM 组合 agent 常跑不赢 1/N 等权。
- 一批时点/防泄漏评测基建：Look-Ahead-Bench、StockBench、Agent Market Arena、LiveTradeBench、OpenPM 等。
- **对「LLM 处理研报」子领域本身：没有针对性的复现失败论文——状态是「未验证」，不是「被推翻」**（本调研最重要的判别）。

## 3. 产业：成熟度、形态与反面锚点

### 3.1 成熟段：研报/分析师数据 → 个股因子（已被产品化多年）

- **华泰金工 FADT 系列**（大机构工业化管线）：文本 FADT（2022-07，`forecast_adj_txt`，只纳入盈利预测调整类强逻辑研报）→ BERT-FADT（2022-10）→ **LLM-FADT（2025-06）**：Qwen3-8b 对研报原文做五角度重构 → FinBERT 编码 → XGBoost 滚动训练；回测 2017-01~2025-05，增强 Top25 相对中证500 **年化超额 27.60%、IR 2.21、月胜率 74.26%** [自报，但为长期产品化跟踪]。2026 年跟踪报告显示**经历回撤周期**（「大模型文本选股策略回撤修复」类标题）。
- **中信建投分析师预期因子**（2020）：预期修正四阶段选股，年化超额 12.22%~18.99%（2009-2019）；超预期因子（ESP）年化超额 22.81%（相对中证500）。**月报产品化延续到 2026** [自称/长期跟踪]。
- **MSCI 分析师情绪因子**（第三方验证）[同行评审级业内研究]：7 个单因子多空组合均为正、多数 t>1.96；**因子自相关仅 0.83**（财报类 0.94-0.99）→ 衰减快、需高换手、季度再平衡可捕捉。
- 注意：以上全部是「研报/分析师数据 → **个股因子**」，**权重合成规则固定，不是 LLM 在调权重**。

### 3.2 空白段：「观点 → 权重」

- 商业数据商：朝阳永续（一致预期库 + 盈利预测因子库 + 投决会仿真辩论 Agent，2025-2026 转向 AI）、慧博、Wind、iFinD、Choice——交付形态是**字段化数据 + 全文库 + 终端/API**；**未见「观点→组合/因子权重」产品**。朝阳永续的辩论式 Agent 是观点消费侧，不是权重侧。
- 海外 AI 投研工具：AlphaSense（生成式搜索/工作产物）、Hebbia（文档智能）——**搜索/摘要/文档智能，不出信号**；Kavout（AI Stock Picker 自称信号）零第三方验证。
- 对冲基金公开实践：Bridgewater AIA Labs、Man Group、Barings（「多智能体围绕投资想法辩论再交 PM」）、Pictet——**流程描述，零业绩归因披露**。
- **结论：占比最重的空白确认——「LLM 读策略研报 → 调因子权重/仓位 + 披露回测」在公开产业界无先例。**

### 3.3 反面锚点（必读）

- **AIEQ ETF**（2017 成立，"AI powered"）：截至 2026-10-16，近 5 年年化 **4.01% vs SPY 12.86%**，全可比区间跑输 [第三方数据 stockanalysis.com]。MarketWatch 系列标题可作媒体侧旁证（"reality hit"）。
- 2026 年国内量化现状：指增超额仍在但拥挤/波动显著（公募 300/500/1000 指增 2026Q3 超额 3.5%/4.4%/3.5%；私募指增近 3 月 500 指增 -11.64%），行业反思集中在风格暴露与模型同质化。

### 3.4 合规边界（与设计直接相关）

- 中证协 2026-10 两份文件：①研报业务 AI 内控——**严禁分析师直接采信未经核验的 AI 生成内容**、须人工核实并留存提示词/修改稿；②风险数据管理与 AI——模型可追溯/可解释、防数据污染，**明确提示「同质化风险」（行业共用相似模型易放大拥挤交易）**。
- 《人工智能生成合成内容标识办法》2025-09-01 施行（生成内容显式+隐式标识）。
- **含义**：监管方向支持「AI 辅助研究 + 人工终审 + 全链路留痕 + 有界使用」，不支持无约束的 LLM 自动调权。

## 4. 与本项目的映射

### 4.1 我们自己的实测数据点（外部结论的内部互证）

- **RD-Agent spike（2026-10-16，tests/validation/2026-10-16-rdagent-spike-validation.md）**：外部 LLM 供给线的诚实闸门读数——翻译覆盖 4/10（缺失面全在 `Ref`，动量/反转/波动族不可表达）、**可翻译者 0/4 过闸**（弱 ICIR / 无增量 / 数据缺口），「外部 SOTA ≠ 过闸因子」在本批实测成立。与外部「Alpha Illusion」结论同构：**别对 LLM 生成/转化的东西自动抱高期望，诚实闸门会把它打回原形。**
- **10-05 多 Agent 调研**（docs/evals/2026-10-05-多Agent对单Agent选型调研.md）：TradingAgents 无单 agent 基线无消融；MAD 不自动优于自一致性。本次调研补充了它的**厂房级证伪记录**（issue #168/#203/#483）。

### 4.2 设计启示（对「研报管线」方案的修正建议）

1. **按待检验假设立项**：该方向「设计合理、验证为空」——初始先验应是「无收益证据」，立项文书里写明，评估设计先行（时点严格 + A/B 一次一变量 + 用存量 L2 榜单回溯倾斜前后前瞻收益）。
2. **证据强度排序**（若要提高「第一个拿到可信成果」的概率）：
   ① 结构化预期数据（评级/目标价/预期修正——30 年同行评审背书，且 Vibe-Trading 已证明 A 股接口可得）→ ② 研报文本因子（华泰产品化在先）→ ③ 宏观叙事观点→权重（零验证）。
   **建议：把宏观观点的定位收敛为「上下文/先验」（§S4 注入路线），而把「权重调整」的首批验证额度留给结构化预期修正类信号。**
3. **我们设计逐条命中生态雷区的反面**（可作为设计卖点与验收红线）：
   - 待确认门禁 ←→ 合规「未核验的 AI 内容不得采信」
   - 有界倾斜（λ 上限 + 勾稽分解）←→ 「无界 LLM 调权」批评
   - `published_at`/`valid_until` 时点结构 ←→ 前视偏差/DeepFund 批评（**须写成硬契约：回测按发布日回放，观点过期即失效**）
   - 报告披露节 ←→ 可追溯/内容标识合规
4. **评测框架参考**：CN-Buzz2Portfolio 的可复现 benchmark 思路 + 本项目既有五道闸/cohort/结算体系。
5. **数据形态现实**：卖方研报全文版权受限（开源生态普遍只用结构化元数据）——「人工投放 + 内部使用」是合理姿势；公开材料只披露方法与聚合统计。
