## 2. 统计口径：0.3 在 n≈130–149 下是什么强度的过滤器

- 日频 IC 序列长度 n ≈ 129–149（20 日窗因子因热身少 ~20 天）；ICIR 估计的标准误
  `SE ≈ sqrt((1 + 0.5·ICIR²)/n)`，ICIR≈0 处 **SE ≈ 1/√n ≈ 0.083–0.088**。
- 阈值 0.3 ≈ **3.4–3.6 SE**：真零 IC 的因子通过概率 ≈ 0.02%–0.03%；真 |ICIR|=0.3 的因子通过
  ≈ 50%；真 0.2 → ≈ 12%；真 0.15 → ≈ 4%。即闸②是**高置信度过滤器**（宁可漏、不可错）。
- 噪声尺度的直观验证：同族不同窗因子 `vol_ratio_5d/10d/20d` 实读 0.238/0.273/0.368——同一经济
  机制的三点读数跨度 ≈0.13，落在 ±1.5 SE 内——**当前 n 下按 ICIR 排序同族因子不可靠**（排序噪声
  大于因子间真实差异）。

## 4. 结论与建议（决策留 owner）

1. **建议维持 0.3**：读数显示闸②在 n≈130 下已是 3.5 SE 的高置信度过滤器；降阈会把「噪声内」的
   读数放行，与「闸门是裁判」的设计立场相悖（且 3 条最强候选已被 ①/④ 正确拦下，说明栈有效）。
2. **真正的改进方向是测量精度与观测性，而非阈值**：
   - **面板深度 150 → 250 交易日**（SE 从 0.086 → 0.063，阈值等价强度升到 ~4.8 SE；同时缓解
     20 日窗因子被闸①贴线拒收的结构性问题——见 extend-factor-dsl-coverage 报告 §3）；
   - **拒收记录携带读数**（当前 `rejections[]` 只有原因码，`missing_rate`/`icir` 等 detail 在通道
     摘要中丢失——本备忘的分布靠复算才拿到；建议外部导入/月批的拒收载荷带上 detail 数值）。
3. 候选池强度问题回到供给线本身（收割桥/更丰富的因子形态），不通过降阈值解决。
