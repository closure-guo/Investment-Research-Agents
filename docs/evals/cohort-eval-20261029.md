## 6. confidence 归因（闸后小节）

**堆积事实**：日主 confidence=0.55 占 38%（41/107）；0.50 ×15、0.60 ×15。分日众数：0.55 是跨窗口持续众数（10-08 即现、10-17 后常态 3~5 条/日），**与 10-13 换模型、10-22 三档 prompt 均无清晰起点关系**。

**人工判读（5 条，Langfuse trader/risk span 原文）**：5/5 均为 **risk_judge 终稿「同向 watch」场景**——trader 报 watch（confidence 0.5 附近），风控终稿改写 0.55；reasoning 显式引用判据文本：①「Decision history: 2026-10-08 neutral(55%) — same direction as watch/hold. So no re-…」（滞回同向延续语义）；②「证据均衡带：是 (RM neutral) — execution actions (buy/sell) MUST have evidence increment…」（均衡带判据命中）。

**结论（三态）**：`prompt-anchor` —— 0.55 是 risk_judge 在「同向延续 watch / 均衡带」场景下的**机制性打点**：非解析器默认值（分布有多样性，0.50/0.52/0.57 等并存），也非纯自由众数（reasoning 引用判据文本）。与 §1.20（10-22 round15，median 0.55、三档 prompt 未移动分布）结论一致且细化到场景。

**处置去向**：与全观望锁定处置同面（软化滞回注入措辞 / 均衡带判据修订，既有候选清单）；在按场景分桶（同向延续 vs 新信号）之前，confidence 禁入校准曲线——本轮已遵守。
