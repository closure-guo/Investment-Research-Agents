## 问题 A：T+20 考核与 1~2 天的信号节奏，在数学上不可能兼容

### 数据（生产库，2026-11-04）

| 事实 | 数值 |
|---|---|
| 同标的相邻分析间隔 | 中位 **1 天**（p25=1，p75=3） |
| 方向翻转率（相邻两次分析 action 不同） | **31.6%**（250 次 transition 中 79 次翻转） |
| 方向性观点 → 下一次同标的分析的间隔 | 中位 **2 天**（p25=1，p75=3） |
| 活过 3 天的方向性观点 | 29.9% |
| 活过 5 天 | **3.4%** |
| 活过 20 天 | **0.0%** |
| 已闭仓方向性观点 | **56 条，全部 `superseded`**（无一条 `expiry`） |
| 活满 20 天的观点 | 15 条，**全部是 neutral 的 `expiry`** |

### 结论

只要「同标的新观点立即 supersede 旧观点」这条规则存在，方向性观点就**不可能**活到 T+20。
`excess_return` 至今为空不是 bug，是机制的结构性结果——**T+20 主指标在当前机制下永远产不出读数**。

### 选项

| 选项 | 做法 | 影响面 | 代价 |
|---|---|---|---|
| **A1 同向不 supersede** | 新观点与旧观点同向 → 不结算旧观点（视为更新/加仓），只有方向翻转才 supersede | 只影响同向重复；翻转率 31.6% 意味着约 2/3 的重复是同向 | 同标的会同时挂多条同向观点 → 已被「按标的聚合」吸收，风险可控 |
| **A2 最小存活期 N 天** | 旧观点存活 < N 天时，新观点记为 `duplicate_of_day`，不 supersede | 改变分析吞吐与落库量 | 会压制正常的方向更新 |
| **A3 冷却期** | 同标的 N 个交易日内不再重复分析 | 直接降低 LLM 成本 | 可能错过真实变化 |
| **A4 改考核节奏** | 承认这是 1~3 天的短周期信号，主指标改 T+3 / T+5（保留 T+20 为辅助） | 只改考核，不改产出 | 需重登记 `metrics.md` §1.9 + 新切点；历史 T+20 口径作废 |

### 建议

**A1 + A4 组合**：

- A1 让「同向重复」不再杀死观点，预计可使一部分观点自然活到 T+20（先小样本观察，不动 A2/A3）；
- A4 把主指标改成与信号节奏匹配的 T+5，诚实反映这是一个短周期系统；
- A2/A3 属于吞吐调控，等 A1 上线观察 2~3 周后再评估。

**不要**只做 A4 不改机制：那样只是在用短窗口掩盖「观点被不断重置」的事实。

## 问题 B：`sell=exit` 被记成空头

### 现状

`sell` 的语义是「持有者减仓 / 未持有者不介入」（fund_manager 原话），执行线把它映射为 `flat`（A 股信号路径不建模做空）；但净值把它按 `short` 记账，于是「组合」= 100% 空头账本（`long_views=0`）。

### 三个选项

| 选项 | 做法 | 同批数据的净值 | 问题 |
|---|---|---|---|
| **B1 保持现状** | exit 记 short | -4.60%（已上线口径） | 与只做多指数不可比；空头敞口是凭空造的 |
| **B2 exit 记 flat** | 与执行线一致，sell 不产生仓位 | **0.00%**（当前无 buy → 空仓） | 净值恒 0，指标失去信息量 |
| **B3 立场加权** | neutral 记 0 敞口但占分母，long/short 按观点等权 | 同批数据约 **-0.86%** | 仍需「账户」定义（资金、权重上限、现金） |

### 建议

**B3 作为终局，但前置是「恢复买入信号」**。当前 27 个交易日 0 条 `buy`，任何口径改造都只是在描述一个空仓策略：
- 若现在切 B2，页面会变成一条 0% 直线；
- 若切 B3，净值接近 0 但至少保留了「立场」语义。

**B1 必须加一条硬约束**：如果继续把 exit 记空头，就必须在净值上明确标注「做空是评分语义，不是可执行仓位」，并在对比指数时给出「负指数」或对冲基准——否则永远无法与宽基比较。

| 事实 | 数值 |
|---|---|
| open buy 观点 | 2026-10-08 起 **0**，至今 27 天 |
| 最近一条 buy | 2026-10-07（次日即被 superseded） |
| 13 条 buy 的结局 | 11 条 1~3 天内被 superseded，2 条 `missing_entry_price` |
| 执行线 | 162 条信号全 `flat`，**0 笔成交**，paper 净值恒 1,000,000 |

**在买入信号恢复之前，问题 B 的任何口径都是空中楼阁。** 下一步应先归因「为什么没有 buy」：是选股档位把标的都判成观望，还是 buy 观点被 1~2 天的 supersede 吃掉了（A1 可同时验证这一点）。

- 不要在 A1 上线前调整 T+20 之外的其它判定阈值——一次只动一个变量。
