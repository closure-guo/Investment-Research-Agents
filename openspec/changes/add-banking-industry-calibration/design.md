# Design: add-banking-industry-calibration

## 决策

### D1 不适用排除优先于编造阈值

spec 明令「新增行业覆盖条目 SHALL 附校准依据，MUST NOT 拍脑袋取值」。银行业偿债/效率指标的两条路：

- **编阈值**（如 资产负债率 (93, 96, False)）——93/96 从哪来？无同业分布校准，纯拍脑袋；且把「存款=负债」塞进制造业杠杆语义本身就是口径错误。
- **排除+标注**（本 delta）：银行风险约束是资本充足率（专项指标二期接入），资产负债率/流动/速动/周转率族对银行无判别意义。诚实语义 = 「行业不适用」而非「阈值不同的同判别」。

排除语义的实现：override 值 None → `_get_thresholds` 返回 None → 绝对灯 None；变化率灯仍按同比评（同比恶化仍可见）？——不。变化率灯对不适用指标同样无意义（负债率同比上升 2pct 对银行不是恶化信号）→ 排除指标 final 恒 None，不参与评分。实现于 `assess_traffic_lights` 入口：行业排除集内的指标直接全 None。

### D2 维度剔除与满分缩放

银行适用指标：盈利（净利率/ROE/ROA）+ 现金流（资本支出/折旧）→ 偿债/效率两维 count=0。现有 `compute_health_score` 对 count=0 维度记 0 分 → 银行满分被压到 50 且 rating 按 100 分段 → 必须缩放：

- 满分 = 25 × 适用维度数（行业排除维度不计入；**数据缺失维度仍计入**——数据缺失记 0 分是诚实信号，行业不适用不是）
- rating 阈值 = 0.85×满分 / 0.60×满分（通用路径满分 100 → 85/60 零回归）
- 健康度结果携带 `score_cap`，报告渲染「X 分（rating，满分 Y）」（cap=100 时不追加，零回归）

判别「维度被行业排除」：维度内全部指标 ∈ 行业排除集（`matched_industry_overrides` 值为 None 的子集）。部分排除（盈利维度排除毛利率，但净利率/ROE/ROA 仍在）→ 维度保留。

### D3 银行业匹配键

`INDUSTRY_OVERRIDES` 键为子串模糊匹配：东财行业「银行」系（国有大型银行/股份制银行/农商行…均含「银行」）一键覆盖；cninfo 降级源返回「货币金融服务」——独立键共享同一覆盖表对象。共享 helper `is_banking_industry()` 供 GARP/图表复用（单一实现，勿三处各写子串表）。

### D4 校准依据（spec 反拍脑袋条款的论证）

- **ROE (13, 6, True)**：光大 FY2025 归母权益口径 ROE ≈ 9.0%（audit 实证 8.996%）；国有大行 8-11%、招行/宁波 13-15%、弱股份行 6-8%。13 绿 = 大行顶/优秀行中枢；6 黄 = 弱行下限。
- **ROA (0.9, 0.5, True)**：光大 ≈ 0.6%（净利/平均总资产）；大行 0.85-1.0%、股份行 0.55-0.8%。0.9 绿 = 大行水平；0.5 黄 = 股份行下限。
- 单样本局限：光大一行为锚 + 公开区间佐证；fail-open + 口径标注使误判可审计；后续银行标的实跑积累后可收紧（指标台账登记基线切点）。

### D5 GARP 豁免走 data 通道而非改签名

`_try_garp` 把 `industry` 塞进 data dict，`calc_garp` 内部判 `is_banking_industry(data.get("industry"))` → 负债率不适用退出 failures + `details["负债率_行业不适用"] = True`。与既有诚实分桶（D1 数据缺失）并列第三类：行业不适用。PE/净利润增长率/ROE 三项判定语义不变。

### D6 信用减值损失列存在即纳入（不做行业门控）

银行利润表与制造业利润表都有「信用减值损失」列；数据存在即计算并进快照（银行是主诉求，制造业同样受益），fetch 层不做行业 plumbing。同比精度沿用快照现有纪律（金额亿元、同比展示精度与既有科目一致）。快照行渲染在「归母净利同比」后追加「、信用减值损失 X 亿（同比 Y%）」，字段缺失零变化。

### D7 图表占位文本：行业不适用 ≠ 数据缺失

银行业标的毛利率恒 None（#240 已断线），占位文本「利润率数据缺失」对银行是误述（数据没缺，是口径不适用）→ collect_chart_data 携带 industry，占位文本分支为「银行业不适用毛利率口径（无营业成本概念）」。全球市场份额占位图移除影响图表数量契约（E2E 段数断言敏感，见 track-record-display-clarity 教训）→ 范围外。

### D8 prompt 豁免指令落方法论段（不新增 spec requirement）

分析师方法论受「分析师反幻觉硬规则」requirement 约束（方法论 MUST 体现周期感知）——银行业豁免句是同段的行业适用性细化，delta 在 industry-threshold-coverage 的 ADDED requirement 内以场景钉住 prompt 行为（金融类标的 OCF 倍数 MUST NOT 作为含金量论据），agent-prompt-contracts 主规范不动（其全部场景仍过）。合并后 deploy prompts。

## 风险

- 健康度评分语义变化（维度缩放）仅银行业触发；通用路径 max=100 数值零回归，测试钉死。
- GARP 银行业 pass 率上升（负债率退出 failures）——这是修死规则的预期行为，估值层语义由 spec 场景钉死（其余三项不变）。
- 快照增列使所有有该列标的的报告快照行加长——披露节行内追加非新章节（#242 断点 1 同纪律）。
