# Design: add-microcap-lane-guardrails

## 退市股池的可得性边界

- 退市清单：公开数据源（交易所/东财口径）；字段 = 代码、名称、退市日（可得时）。
- 价格历史：优先既有回填通道按代码补采；数据源无历史时如实标注 `history_missing`，不伪造。
- 时点可见性：`list_date ≤ t ≤ delist_date`（`delist_date` 缺失时按「截至抓取日已退市」处理并在池输出注明口径）。

## 档位参数（单一来源）

| 参数 | main（现状） | microcap |
|---|---|---|
| `min_avg_amount_20d` | 5000 万 | 1000 万（配置） |
| `min_trading_days` | 60 | 60 |
| 建议单票上限（记录字段） | — | 5%（配置） |
| 滑点档位（记录字段） | — | 提升一档（配置） |

## 前置门禁判据

- 含退市股池就绪 = 退市清单已抓取且退市标的已进池构建逻辑（回归测试在案）。
- 拥挤度数据就绪 = `regime_daily` 存在最近交易日行（变更 2）。
- 两判据均为纯代码检查；批次记录进 `frontier_gate` 字段（`ready` / `observation_only` + 缺失项列表）。

## 边界

- v1 不含 UI；批次数据经既有 API 读取与人工验证。
- 不接执行链、不做小票专用滑点回测（执行接通与扣费回测属后续立项）。
