## Context

cohort 日批 9-25 上线（`paper-trading-cohort` spec），现行数据：245 次运行 / 183 成功 / 10 只票各 16~21 个有效样本；`cohort_runs` 记账（含 session_id / langfuse_trace_id / token）可直接 join `predictions`；citation 三项 Score 在 Langfuse 上 183 条 trace 全覆盖，judge 四维分从未挂上（评估批次专属，日批 trace 无）。窗口内发生了两次供给面切换：10-13 分析 LLM（kimi→deepseek，日 token ~0.8M→~2.1M）与 10-17 judge 切换；10-09 / 10-16 两日 provider 配额熔断整批归零。评估约束沿用 `docs/evals/metrics.md` 台账体系与评估 SOP（一次一个变量、先归因再处置、人工终裁为终审）。

## Goals / Non-Goals

**Goals:**

- 四轨道（供给成本 / 过程质量 / 方向能力 / 日频价值）各自出读数，轨道间不加权合成。
- 中性观望（neutral）获得可计算的对错判据：反事实超额收益分布。
- 所有检验以交易日为统计单位（同日横截面均值→跨日），承认 cluster 结构与当前功效上限。
- confidence 0.55 堆积在进入任何下游使用（校准曲线、置信加权）前被归因。
- 读数可复现：脚本只读、入 `scripts/`、产物入 `docs/evals/`、`runs.jsonl` 记行。

**Non-Goals:**

- 不跑 judge 四维批（花 judge 配额，单独立项拍板，本 delta 零 LLM 成本）。
- 不改分析链路 / prompt / 结算 / 执行链的任何行为。
- 不在本轮下「选股能力优于基准」级结论（五周单行情窗口 + 0 条 long，功效与覆盖都不支持）。
- 不处置全观望锁定（本评估产出其证据材料，处置走既有候选 delta 流程）。
- 不做每票内部配对显著性检验（n≈20 边际，只做 pooled 与描述）。

## Decisions

### D1 四轨道分离，禁止合成总分

单一合成分会把供给成本、报告质量、方向能力搅在一起，任何一项恶化都会被其他项稀释，且四者的行动责任方不同（运维 / prompt / 决策层）。各自独立读数、独立结论。**轨道定义与判据：**

- **A 供给**：按「每成功一份」归一——`tokens_per_success = Σtokens_total / Σsuccess`、成功率、预算占用（cohort 当日 token / COHORT_DAILY_TOKEN_BUDGET）。分段报。判据示例：单份成本与预算占比是否支持继续日频。
- **B 过程**：citation 三项按日均值时间序列 + 分段对比；断点归因到换模型日（10-13 / 10-17）而非「分析师变差」，遵守先分桶再定罪。
- **C 方向**：见 D3/D4。
- **D 日频价值**：翻转率 = 每票每周方向变动次数的池内均值；保鲜期 = T 日观点方向与 T+k 日实现超额的符号一致率按 k 递减曲线。仅描述。

### D2 窗口切分为硬约束

三段：`W1 = 9-25~10-10`（kimi）、`W2 = 10-13~10-16`（deepseek+旧 judge，含 10-16 熔断日剔除）、`W3 = 10-17~读数日`（deepseek+新 judge）。段内出结论；段间差值只允许作为「换模型影响」专案记录，不得并入任何轨道结论。熔断日（10-09 / 10-16）从 A 轨成本均值中剔除、单独列示（属供给事故非常态成本）。窗口边界来自供给面事件表，登记在 `metrics.md` §1，后续新增切换事件时增段。

### D3 neutral 反事实读法（本 delta 的核心新判据）

观望无持仓盈亏，其判据只能是反事实：**neutral 观点发出后 T+1 开盘至 T+20 收盘，该股相对基准（沪深 300）的超额收益 r_e**。计算由评估侧**只读自算**（`market_snapshot.db` 收盘序列 + `index_closes` 基准），不依赖 `decision_settle_daily` 的结算调度、不写 `predictions` 任何字段——理由：①neutral 的对错不该被结算排期卡住（open 的 70 条现在就要进读数）；②评估口径与结算口径解耦，避免改结算行为。判读：池内 r_e 分布中心 ≤0（观望躲开的票没跑赢）⇒ 系统观望自洽；分布中心显著 >0 ⇒ 锁定在系统性错过机会（进处置证据）。同票同日多条 neutral 去重（同票取当日最新一条，与 predictions 判定口径一致）。

### D4 统计单位 = 交易日（cluster-robust 的简化实现）

同日 10 只受共同市场冲击，非独立样本。实现：先算每个交易日的横截面均值（neutral 反事实均值 / 成功率 / citation 均值），再跨日做单样本检验（n=有效交易日数，W3 约 10 天）。坦白登记功效上限：W3 段 n≈10，只能检出大效应；读数报告必须带「本段 n」与「未达显著 ≠ 无差异」声明，与 `formal-backtest-2026q3` 报告口径一致。

### D5 confidence 0.55 归因闸

未归因前，confidence 字段禁止进入本程序任何下游使用（校准曲线、按置信分组读数）。归因路径：按 (日期 × 方向) 分桶看 0.55 堆积的起止日是否与 10-13 切换重合；抽 5 条 0.55 样本的 trader/risk 输出原文人工判读（prompt 锚定 / 枚举默认值 / 真实众数三选一）。产出单独归因小节，结论三态：`prompt-anchor` / `default-fallback` / `genuine-mode`，处置去向分别为 prompt delta / 解析器检查 / 保留并记录。

### D6 short/long 结算读数挂结算到位闸

方向性胜负（resolved_win / resolved_loss）当前仅 3 条分胜负，不足以下结论。C 轨结算读数的**正式版**设闸：open 方向性观点（short 13 / long 0 + 后续新增）到期数 ≥30 或 11-15 到期潮过后，取下一轮；当前只允许标 `preliminary` 的中期行。防止小样本胜负比被误读。

### D7 产物与复现

- 脚本 `scripts/cohort_eval_readout.py`（只读；参数：`--as-of` / `--universe-version`），单文件、无 LLM 调用、输出 JSON + Markdown 双产物。
- 报告落 `docs/evals/cohort-eval-<日期>.md`（轨道分节 + 三前置小节 + n 声明）；`runs.jsonl` 追加一行（run / HEAD@启动 / means 摘要）。
- 口径先行：`metrics.md` §1 登记全部指标定义（分母 / 窗口 / 剔除规则），再写取数代码——顺序在 tasks 中为硬依赖。

## Risks / Trade-offs

- **反事实收益与结算口径可能不一致**（评估自算 vs settle 落库）：接受——两者服务不同问题（自算管 neutral 判读、结算管胜负记账），读数报告需并列披露口径差；若差异大，升 issue。
- **W3 段 n≈10 功效不足**：接受并显式声明；这本身是「固定 10 只日批」的内在上限，读数目标是对话式量级感而非显著性裁决。
- **行情源缺日**（停牌 / 数据缺口）：反事实计算遇缺日时该样本剔除并计数披露（`missing_bars`），不插值。
- **单文件脚本可能长尾膨胀**：首轮接受（评估脚本非生产代码），若二轮扩展（judge 批接入）再拆模块。
