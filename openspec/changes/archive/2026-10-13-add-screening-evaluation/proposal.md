# Proposal: add-screening-evaluation

## Why

- 选股模块最大的自欺风险是"回测好看、实盘不行"：候选池必须从上线第一天起做前向跟踪，不能只信历史回测。
- 「因子打分选股是否有超额」与「L3 LLM 粗筛是否有增量」都不能预设为真，需要消融变体由配对 bootstrap 裁决（同辩论层消融的先例）。
- LLM 挖掘因子 vs 手工 builtin 因子的对照是因子挖掘管线的终极考核，必须在评估设计里显式登记。

## What Changes

- 候选池前向跟踪：每日候选池（含 L2 全量名单）落库后，自动跟踪入选后 5/10/20 交易日收益（复用 outcome 日批结算设施），区分 Top-N 入选组与落选对照组。
- 新增选股消融变体：「因子打分选股」vs「随机选股（固定种子）」vs「等权指数基线」，共享同一时段与持有窗口（horizon 对齐），配对 bootstrap（B=10000）报告。
- 「±L3 LLM 粗筛」变体：比较粗筛前后候选池的前向收益与踩雷率（drop 组后续 20 日收益显著低于 keep 组方支持粗筛价值）。
- LLM 因子 vs builtin 因子分层统计：两组因子各自驱动打分的前向表现对照，作为因子挖掘管线的考核指标登记进 evals 报告。
- 全部统计遵循既有口径：CI 含 0 只写「无显著差异」，有效 n 与适用口径在报告中披露。

非目标（Out of scope）：

- 不改动现有决策回放（decision-backtest）的契约。
- 不做真实资金的 A/B 对照。

## Capabilities

### Modified Capabilities
- `evaluation`: 新增选股前向命中率与分层统计契约。
- `causal-ablation`: 新增选股三变体与「±L3 粗筛」变体契约。

## Impact

- **后端**：`evals/screening/`（新增）、`outcome/` 结算复用扩展。
- **测试**：前向收益计算单测（时点截断）；变体 wiring 单测；随机选股种子可复现单测。
- **验证**：上线后每 20 个交易日产出一次前向跟踪报告，落 `docs/evals/`。
