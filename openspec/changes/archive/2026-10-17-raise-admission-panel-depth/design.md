# Design: raise-admission-panel-depth

## D1 为什么是 250：两条量化依据（复审备忘 §2/§4）

- **闸②估计精度**：ICIR 标准误 `SE ≈ 1/√n`。150 日（有效 ~130–149 点）→ SE≈0.086；250 日
  （有效 ~230+）→ SE≈0.063。同一 0.3 阈值从 ≈3.5 SE 升到 ≈4.8 SE——「高置信度过滤」更强，
  同族因子排序开始有分辨力（排序噪声从 ±1.5 SE 降到 ±1 SE 内）。
- **闸①结构性贴线**：闸①缺失率含热身期 NaN。20 日窗：150 日面板 13.3% 热身 + 6.1% 基线
  ≈20.1%（实测 0.20117 > 0.2 拒）；250 日面板 8% + 6.1% ≈14.1% ✓。
- 数据前提：回填扩至 2025-06-03，可用 334 日（字段齐备率 100%）——250 有裕度，且为后续进一步
  加深留空间（300+ 亦可构造）。

## D2 只动深度：阈值/公式/监控口径全部不动

- 闸①–⑤ 的阈值与公式（MAX_MISSING_RATE / MIN_ABS_ICIR / BH_FDR_Q / 冗余 / OOS 切分）零改动；
  衰减监控面板（DECAY_WINDOW+30）零改动——「准入面板」与「衰减面板」独立是既有设计。
- 历史闸口读数不可与新读数直接比较（样本量变了）——报告须标注面板深度；已入库因子不回溯重评
  （其准入读数在其时面板下成立，衰减监控另行把关）。

## D3 fail loud 与回填的次序纪律

- 常量改 250 后，可用历史 < 250 的快照库会使三准入入口 fail loud——因此**回填必须先于常量合并**
  （回填完成 → 覆盖率核验 → 再合并）。回填区字段齐备率（amount/high/low）已按八列契约核验。

## Risks / Trade-offs

- 面板加深会改变全部新候选的闸②读数（更稳，但也可能使边缘因子读数下移——更接近真值）。
  这是「测量更准」的必然，不是回归；报告按新旧面板对照呈现。
- 334 日可用 vs 250 下限：若未来快照库收缩（数据事故）→ fail loud（设计如此）。
