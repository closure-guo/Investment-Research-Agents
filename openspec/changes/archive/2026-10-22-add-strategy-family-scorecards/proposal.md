# 策略族成绩单（add-strategy-family-scorecards）

## Why

2026-10-18 调研（`docs/evals/2026-10-18-个人小资金量化策略调研.md`）结论：胜率是「小赢多次、偶发巨亏」负偏度结构的展示面，不能作为目标函数；评价体系必须能回答四问——扣费后到底赚不赚、最惨一次亏多少、这种玩法最多装多少钱、有没有「一次亏光」类极端样本。当前系统只有单一胜率/均值读数（`outcome/store.py::decision_stats`），无法回答四问；且后续三项变更（拥挤度总仓位系数、事件驱动线、小票通道）都需要统一的族级成绩单作为验收与护栏口径。本变更是该程序的第 1 项（顺序见调研备忘录 §4.2，顺序不可反）。

## What Changes

- **新 capability「strategy-scorecards」**：
  - **策略族注册与口径声明**：注册表驱动（初始两族：观点线 `decision`、执行线 `execution`——paper 台账）；每族声明数据源、收益口径、费后处理与样本门槛；口径先登记 `docs/evals/metrics.md` §1 再动代码。
  - **四槽成绩单**：期望值（毛/净双值 + 样本量；样本不足 → null + `insufficient_sample` 标注）、最大回撤（族级累计曲线）、容量提示（最近样本标的近 20 日日均成交额 × 参与率上限 → 建议资金上限）、极端样本清单（默认阈值 −15% 可配置）。缺数据一律 null + 原因，不折算 0。
  - **胜率展示定位**：胜率/命中率字段保留为展示字段；MUST NOT 作为任何自动处置、门禁或告警判定的输入。
  - **只读端点**：`GET /api/scorecards`。
- **frontend ADDED「战绩页策略族成绩单区块」**：族切换 + 四槽卡片 + 极端样本明细表 + 口径注释随行；四槽为主位，胜率类字段不在主位。
- **口径登记**：`docs/evals/metrics.md` §1 新增「策略族成绩单」口径小节（先登记后动代码）。

## Impact

- 口径：`docs/evals/metrics.md` §1 新增小节；非实验轮，不加时间线行。
- 代码：`src/finance_agent/outcome/scorecards.py`（新增，纯函数 + 只读查询）+ `api.py`（新端点）+ `frontend`（战绩页区块 + types）。
- 数据：无新表——只读既有 `predictions` / `paper_equity` / `positions` / 快照成交额。
- E2E：战绩页成绩单区块入默认套件（stub 数据，不 mock 业务接口）。
- 非目标：不做选股族与事件族（注册表可扩展，事件族由后续变更登记）；不做任何自动处置；不改既有战绩统计的输出行为（纯增量）。
