# Design: add-market-data-fallback

## Approach

**回退顺序**：全市场 spot 固定为「东财 → 新浪 → None」。东财主源只是 IP 级封禁下不可达，一旦解封即恢复直连（零成本、零单位换算），故不回退链倒置、不引入配置开关。日批（`run_market_snapshot_batch`）在 spot 为 None 时抛 `SnapshotError` 并写失败标记——MUST NOT 静默写空快照的既有语义完全保留，本次只改变「None 出现的条件」。

**列映射与单位口径**（`_map_sina_spot_to_em`，纯函数）：

日批实际消费的 spot 列清单（逐列核对 `src/finance_agent/data/snapshot.py` 行构造：`build_snapshot_rows`/`_spot_row`/`compute_rebase_factors`）：

| 日批消费列 | 新浪列 | 处理 |
|---|---|---|
| 代码 | 代码 | 去 sh/sz/bj 前缀 → 6 位数字（日批/证券主表/复权基准全按 6 位匹配） |
| 名称 / 最新价 / 涨跌幅 / 今开 / 最高 / 最低 / 昨收 / 成交额 | 同名 | 原值透传 |
| 成交量 | 成交量 | ÷100：新浪单位股、东财单位手（快照 volume 与东财日线/日批同口径，混表可比） |
| 最新价（停牌行） | 0.0 | 归一为 NaN：交 D2 停牌合成路径（0 值直通会写出 close_raw=0 污染 qfq 序列） |

「列形保真」：输出列集合恒为上述 10 列；新浪缺失的列（上游列名漂移）补 NaN 保持列存在；新浪多出的列（涨跌额/买入/卖出/时间戳）丢弃。新浪 spot 无 振幅/量比/换手率/市盈率*/市净率/总市值/流通市值——日批不消费，MUST NOT 编造；单标的行情/同业估值路径（`_quote_via_chain`）以腾讯为主源，本次不动。

**回填同款回退**：`fetch_symbol_history_raw_qfq`（东财 `stock_zh_a_hist` 双口径）失败时回退新浪 `stock_zh_a_daily` 双口径（`adjust=""` + `adjust="qfq"`），列名 date/open/close/volume → 日期/开盘/收盘/成交量，volume 同款 ÷100 归一到手，合并仍按「日期」内连接（任一腿失败/空/缺列 → None，不产出半口径数据）。回填行的 volume 因此与东财来源行同口径。

## Alternatives Considered

- **腾讯 qt 批量（`qt.gtimg.cn/q=sh600519,sz000001,…`）作为全市场源**：需自维护全市场代码表并分批拼串（无「一次拉全市场」接口），且字段位序为本项目金样本钉死的单标的串——列为首选后续项（东财持续封禁 + 新浪不稳时再上），本次不做。
- **回退链倒置（新浪为主源）**：东财解封后无需换算/无前缀差异，主源保持东财可零行为漂移恢复；新浪 70 页分页（≈13s）也更慢。
- **新浪 spot 原样透传 + 在日批侧做归一**：日批行构造（`snapshot.py`）是跨源共用的纯函数层，把源差异（前缀/单位/停牌 0 值）下沉到客户端才不污染日批契约；且 `build_snapshot_rows` 的既有测试与语义不动。
- **`fetch_market_spot` 返回 `(df, source)` 元组**：破坏既有调用方与测试的返回契约；改用客户端属性留痕（`last_spot_source` + `sources_seen["market_spot"]`）。

## Risks

- **新浪 spot 分页更长（70 页 / ≈13s）且官方注明「重复运行会被暂时封 IP」**：回退只在东财失败时触发（当前为常态），单日一次调用；若两源都被限流，日批按既有失败语义告警，不写空快照。
- **回填补齐的东财失败成本**：东财封禁下每票先付一次失败重试（实测 0.4s 失败 + 3 次尝试线性退避 ≈ 5s/票）→ 全市场 5500 票回填约 7–8 小时额外等待。本次不引入源健康冷却（属新能力，避免夹带）；如需，后续以「连续 N 次东财失败 → 本进程内直接走新浪」或 `--source` 参数补。
- **单位换算口径（volume 股→手）是源差异归一的隐含契约**：若新浪上游改单位，快照 volume 会静默差 100 倍；以单测（含真实响应形状夹具）钉死，并在 docstring 注明。
- **新浪 spot 无估值列**：若后续把该映射帧接入同业/估值路径，PE/市值将为缺失——当前不接入（腾讯主源覆盖），后续接入需先补该路径的缺口语义。
