# Proposal: update-outcome-band-volatility-scaled

> **状态：2026-11-28 owner 拍板「按建议序列修」，进入实施。** 拍板范围 = 原提案三项
> （连续超额主指标 / ±2% 降辅助 / 带宽波动率自适应）+ 实施期增补 2 项（同窗随机基准
> 对照、去重标的数披露）——增补出自 2026-11-28 准确性审计：现报「66.7% 胜率」在同样
> 窗口里随机股票有 66% 也会「赢」，没有对照的胜率不能作为能力读数。
> 出处：2026-11-06 零买入修复计划 Task 9；台账提案小节 `docs/evals/metrics.md` §1.24；
> 准确性审计结论 `docs/evals/` 场景见 `tests/validation/`（2026-11-28）。

## Why

±2% 固定中性带对 20 日窗口 1σ=8–19% 的标的分辨率不足（带宽不到单日波动一半，
日内噪声即可把真实方向性判断打成 neutral）；二元 win/loss 把连续结果扔掉——检测
3% 的真实超额需要约 275 条样本，连续值口径只要约 88 条。同时 ±2% 带在决策链里被
当成风险预算使用（12/201 看多中 6/12 提及带宽、107 条 watch 中 63 条提及 σ），
是零买入锁死机制的组成环节之一。

**实施期新增理由（同窗随机基准）**：2026-11-28 审计以全市场等权为对照复算——系统
「退出」观点在结算窗口内的平均超额显著好于随机股票，71 次「退出」中 5~10 日后被叫
退出的股票平均落后指数 1.6%、而随机股票落后 2.5%；即「回避对了」很大程度是市场
在跌，不是选股能力。战绩页只报胜率、不报对照，会把 beta 读成 alpha。故主读数 SHALL
与「同窗全市场等权随机股票」并排展示，并同时披露去重标的数（防同一标的多条观点
重复计数冒充样本量）。

## What Changes

1. **主指标改连续超额**：平均超额、中位超额、超额胜率（>0 占比）、超额 IR（均值/
   标准差，附 t）+ 去重标的数成为主读数；resolution 状态机照旧（resolved_* 继续
   产出，兼容），胜率降为辅助分层。
2. **±2% 降为辅助分类**：继续写库、可查，但降为分层切片，不再用于对外结论句。
3. **带宽改波动率自适应**：辅助分类带 = `max(1.5%, 0.5 × 20日窗口波动)`，窗口波动 =
   决策归属日前 20 个交易日日收益标准差 × √20；波动不可得 → 回落 2%；按行计算并
   落库 `neutral_band_used`（切点前已结算行保持 NULL，不回填）。
4. **同窗随机基准（增补）**：`GET /api/v1/track-record/overview` 追加 `baseline`
   块——同窗口、全市场等权（`market_snapshot.close_raw`，基准 000300.SH）的随机股票
   平均超额；缺数据如实披露「不可用 + 原因」，不折算 0。
5. **去重标的与分段披露（增补）**：`continuous.distinct_symbols`、`band.settled_with_band`
   （切点后带带宽落库的已结算条数）随总览返回；战绩页读数条并排展示。

## Capabilities

- **Modified Capabilities**: `track-record`（判定规则（Outcome Resolution）：
  中性带计算式从全局常量 ±2% 改为按行波动率自适应；基础统计：连续超额族升为主
  读数 + 去重标的数；新增「同窗随机基准」需求）

## Impact

- `src/finance_agent/outcome/track_record/`：judgment（带宽计算 + Resolution 带带宽）、
  model（`neutral_band_used` 列 + 连续统计 + 去重标的）、job（superseded/expiry 落带宽）、
  baseline（新模块：同窗随机基准）、api（overview 三块新读数）。
- `src/finance_agent/data/snapshot.py`：`read_close_map`（多日全市场收盘，只读）。
- 前端：战绩页读数条（连续超额 / 同窗随机股票 / 带宽披露）+ `types.ts`。
- 主账本页与 track-record API 双轨输出：旧带（胜率）与新口径（连续超额）并排 2 周，
  由 owner 评估主读数切换。
- 与零买入修复的解耦：本提案只动结算读数口径，**不动决策提示词**（后者由消融
  实验 Task 4/5/6 单变量处置）。
