# 可转债覆盖（add-convertible-bond-coverage）

## Why

2026-10-18 调研结论：可转债是个人可用的制度红利品种（T+0、免印花税、条款博弈），机构受容量限制吃不下；但当前系统零覆盖（src/openspec 全库 grep 无命中）。当期市场读数决定了正确形态：双低均值 208.6、价格 <110 元仅 20 只（几乎无便宜标的）+ 信用违约已现实化（搜特/岭南）——因此本变不做「双低轮动」照搬，而是**条款事件（强赎/下修/回售）+ 信用与强赎风险要素**，接入既有事件观察清单。本变更是该程序第 4 项后半（顺序见调研备忘录 §4.2）。

## What Changes

- **可转债标的主表与行情落库**：转债代码、名称、正股映射、转股价、转股溢价率、剩余规模（可得范围内）+ 日行情（价格/成交额）；幂等；时点纪律；失败重试与如实留痕。
- **条款事件落库与状态推导**：强赎 / 下修 / 回售公告落库（公告日 = 可得时点）；确定性状态推导（强赎倒计时剩余交易日、是否已触发；不适用 LLM）。
- **观察清单接线**：条款事件进入既有事件观察清单（复用清单端点与选股页区块，`source=cbb`），条目附风险要素（价格、溢价率、剩余规模、强赎倒计时）。
- **口径登记**：`docs/evals/metrics.md` §1 新增小节。

## Impact

- 代码：`data/`（转债数据抓取）、事件存储扩展（转债行情与条款事件表）、清单构建（`source=cbb` 分支，规则化标注）、`outcome/scheduler.py`（新日批 job）。
- 数据：`EVENTS_DB_PATH` 库扩展表（`cb_quotes` / `cb_events`）。
- 行为：纯增量——不影响股票筛选/决策/执行；不产生订单。
- 非目标：不做双低轮动选股与转债回测选股（当期无标的）；不接执行链；不做转债专用 LLM 分诊（v1 规则化标注）。
