# Design: add-convertible-bond-coverage

## 数据源与字段（实现期以 akshare 当前可用接口为准，字段映射表落实现）

- 标的要素：转债代码、名称、正股代码、转股价、转股溢价率、剩余规模。
- 行情：交易日、收盘价、成交额。
- 条款事件：强赎 / 下修 / 回售公告（公告日 + 关键要素）。

## 存储（`EVENTS_DB_PATH` 库扩展）

- `cb_master`：转债标的（代码唯一）
- `cb_quotes`：日行情（交易日 + 代码 唯一）
- `cb_events`：条款事件（事件类型 + 代码 + 公告日 唯一；状态推导为读时纯函数）

## 清单接线

- 清单条目 `source ∈ {earnings, cbb}`；cbb 条目为规则化标注（无 LLM），风险要素随行。
- **载荷键名冻结（跨变更契约，2026-10-18 裁决）**：`price` / `premium_rate` / `remaining_size` / `call_countdown_days`（`remaining_size` 单位 = **亿元**，`premium_rate` 单位 = %）；前端（事件观察区块）已预留四个读取位，缺值一律 `—`（MUST NOT 折算）。本变更实现 MUST 按此命名与单位输出。
- 复用变更 3 的清单端点与选股页区块（需求已含来源标识字段）；本变不新增页面。

## 边界与非目标

- 不做双低轮动/转债选股回测（当期无双低标的；调研备忘录 §2 当期读数）。
- 不接执行链（不产生订单）；不做转债专用 LLM 分诊。
- 行情源若不含成交额字段，则该字段如实置空并在清单注明（MUST NOT 估算）。
