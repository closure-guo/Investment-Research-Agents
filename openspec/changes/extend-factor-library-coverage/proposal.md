# Proposal: extend-factor-library-coverage

> 状态：立项提案，待 owner 评审（2026-11-27）。本提案只写 spec，未改任何代码。
> 依据：`docs/superpowers/research/2026-11-27-factor-library-gap-research.md`（同日缺口盘点，逐条带出处）。

## Why

因子库在册的 12 条因子全是「成交量 + 日内波动」一类信号：写公式的语言只认 6 个价量字段，市值、换手率、行业、大盘这些原料要么写不进公式，要么没接到因子链。缺口有四种性质，其中「数据面没有」的大头（基本面、另类数据）现在还做不了，但另外三类**现在就能做**：计算器缺按钮、原料没接线、以及一个让约 398 条存量公式白死的计数口径。本 delta 把这三类一次补齐——可表达的原料从 6 个价量字段扩到「9 个字段 + 行业分组 + 19 个新算子」，供给侧最多可解锁约 400 条存量候选。

## What Changes

- **T1 公式语言扩表达力（零新数据）**
  - 自由参数改按「去重后的数值」计数：同一个窗口数字重复出现只算一次，上限 3 不动。实测存量 814 条「复杂度超限」里约 398 条因此可过。
  - 新增 19 个算子：比较与条件（`gt/lt/ge/le/eq/ne/if_else`）、滚动中位数 / 偏度 / 峰度 / 分位数、窗口内计数、线性衰减均值、距极值点期数、滚动回归残差 `ts_resid`、全市场均值 `cs_mean`、行业中性化 `ind_neutralize`、指数函数 `exp`。
  - 新增 3 个可选参考字段：流通市值 `float_cap`、换手率 `turnover`、上市天数 `listed_days`（均不复权口径，面板按需携带）。
- **T2 因子参考数据面（新 capability）**：在快照库内新增侧表 `market_ref_daily`（流通市值 / 总市值 / 换手率），历史由新浪历史日线的流通股本与换手率回填，增量复用拥挤度日批已在做的全市场市值取数；证券主表新增行业门类列；快照读路径以 LEFT JOIN 附加这些列，`market_snapshot` 既有行一行不改。
- **T3 准入与治理**：内置基线包由 5 条扩为 7 条（新增真实口径的流通市值规模、20 日平均换手率，作为新字段的第一批消费者）；引用面板未携带字段的候选在闸①干净拒收（不再让整批崩）；因桶配额退役的因子被同构重提时沿用原桶（堵住「换个类别标签绕过配额」）。
- **T4 提案侧**：提案 category 枚举由 5 类扩为 9 类（新增 事件状态 / 规模 / 残差 / 行业相对），提示词模板同步新算子、字段与计数口径。
- **T5 披露**：选股日批摘要新增 `factor_value_gaps`，列出 as_of 当日因子值几乎全缺的 active 因子（新字段带来的新失效模式，不静默）。

无 **BREAKING** 变更：新算子 / 字段 / 类别均为增量；计数口径只放宽不收紧；既有 12 条 active 因子的表达式、读数与准入结论不变。

## Capabilities

### New Capabilities

- `factor-reference-data`: 因子参考数据面——侧表与增量落库、历史回填、读路径附加列与面板可选字段 / 行业分组的构造、缺失语义。

### Modified Capabilities

- `factor-dsl`: 「因子表达式可解析契约」扩展算子枚举与可选参考字段；「复杂度硬约束」的自由参数改为去重数值计数。
- `factor-library`: 「builtin 因子注册路径」基线包 5 → 7 条；新增「可选数据字段的可计算性」「同构重提的桶归属」。
- `factor-proposal`: 「提案输出合同」的 category 枚举 5 → 9 类。
- `stock-screening`: 新增「因子当日值缺口披露」。

## Impact

- **代码**：`factors/dsl.py`（算子表 / 字段集 / 计数）、`factors/eval_engine.py`（新算子求值、面板可选字段与分组）、`factors/validate.py`（闸①字段预检、桶归属）、`factors/builtin.py`、`factors/propose.py`（CATEGORIES）、`factors/style_exposure.py`（篮子随基线包自动扩展）、`data/snapshot.py`（侧表 DDL、主表行业列、读路径 JOIN）、`data/akshare_client.py`（腾讯批量解析扩展换手率 / 总市值）、`data/snapshot_job.py`（周一行业增量补抓）、`outcome/regime/job.py`（取数链落侧表）、`screening/pipeline.py`（缺口披露）、`scripts/`（参考数据回填脚本、行业回填脚本）、`prompts/factor_proposal.md`。
- **规范联动（不改其 requirement，仅依赖）**：`add-cross-section-translation-path`（B1，横截面转译路径）与本 delta 互补——本 delta 不动生成侧契约条款；`update-harvest-factor-category` 的生产迁移执行是本 delta「同构重提桶归属」生效的前提；`add-analyst-revision-factors` 是并行的第一个非量价族，本 delta 不重复其契约。
- **数据与运维**：新增两次容器内回填（参考数据历史约 5500 票、行业门类约 5500 票），均在日批窗口外执行；提示词模板变更后须 `uv run python scripts/deploy_prompts.py` 发布。
- **测试**：纯后端与数据面变更，不涉及前端 / SSE / 会话流转，**不触发 E2E 门禁**（前端风格标签对未知名原值回退，无需改动）；需人工验证回填后的真实读数，报告落 `tests/validation/`。

## 需要 owner 拍板的点

1. **自由参数计数口径**：改为去重数值计数（建议采纳）。这是对 2026-10-19 治理裁决 D4「自由参数按 AST Number 节点总数」的口径修订——上限仍为 3，与 D4「优先评估不增加拟合自由度的表达形态，而非抬上限」同向；需在 `docs/factor-governance.md` 追加修订记录。
2. **内置基线包 5 → 7 条**（建议采纳）：新基线作为新字段的第一批消费者，同样走五道闸，不放宽。
3. **行业分类主源**：巨潮逐票（已有降级链、2026-11-27 实测可用）为主，批量源（申万 / 同花顺成分接口）作探针备选。
4. **外部生成器恢复与存量重放**：属运维决策（provider 续费 + 重开研究开关）。**修正（实施期核对）**：`replay_factor_harvest.py` 对每条候选都重新调用 LLM 转译（不复用已记录 qlib 表达式）——「translator 阶段零 LLM 重放」不成立。本 delta 上线后先做**离线确定性复译测量**（对状态文件已记录的 834 条 qlib 表达式重译 + 复杂度复验，零 LLM、零生产写入）；生产重放（写库、834 次 LLM 转译、且 LLM 非确定性会污染单变量归因）另行确认。
5. **后续 delta 排序**（见下）。

## 分期与后续 delta

本 delta 内部按三段交付，每段独立可验证：**P1** 算子与计数口径（T1 的 DSL 部分）→ **P2** 参考数据面与字段（T2 + T1 字段 + T3 + T5）→ **P3** 提案侧与存量重放（T4 + 运维动作）。

以下各项**数据源已于 2026-11-27 在容器内实测可得**，但依赖本 delta 的机制或更前置的裁决，**另立 delta**：

- **两融余额与龙虎榜**（上交所 / 深交所融资融券明细、新浪龙虎榜日报，历史可按日回填）：复用本 delta 的参考数据面机制；两融只覆盖两融标的，需先落地 `add-analyst-revision-factors` 的值因子闸①口径。
- **基本面 PIT 面板**（新浪财务指标逐票可得，86 列；按法定披露截止日做保守时点近似）：前置是多 horizon 评估与面板加深——500 日面板对 T+20 做非重叠采样只有约 25 个样本，统计上不可检验。
- **分析师预期修正**：已有 `add-analyst-revision-factors`（0/10），直接实施。
- **横截面转译**：已有 `add-cross-section-translation-path`（0/9），直接实施。

## 明确不做（及原因）

- **降 |ICIR| 门槛、放宽转译纪律、用验证段挑 horizon**：2026-10-28 杠杆分析明确不建议。
- **把快照里的涨停封板 / ST / 停牌列开口给 DSL**：历史回填区这些列是写死的 0（`scripts/backfill_market_snapshot.py`），只有最近约 30 个交易日是真值，直接用会算出假因子。事件计数改由比较算子从价格派生（如「近 20 日涨幅 ≥ 9.5% 的天数」），上市天数由主表上市日期派生。
- **总市值字段**：新浪历史日线只有流通股本，总市值无历史，闸①会长期不过；本期只落库不暴露。
- **多 horizon 评估**：当前没有消费者（无慢变量数据），且如上统计上不可检验。
- **EMA / 滚动协方差 / 回归斜率 / tanh**：可由既有或新增算子派生，或需求很低（点名 ≤ 4 条）。
- **北向 / 股东户数 / 机构持仓 / 授权一致预期 / 文本情绪 / 日内逐笔**：数据源未探明、需付费或需 LLM 抽取，不在本期。
