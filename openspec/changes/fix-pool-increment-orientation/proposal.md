# Proposal: fix-pool-increment-orientation

## Why

2026-10-19 全链复跑暴露首个「可能被闸门口径误杀」的实证样本：`max_ret_5d`
（`ts_max(日收益,5)`）**通过闸②**（|ICIR| ≥ 0.3）、通过闸③，倒在闸④——因为它的 IC 是
**稳定负向**（训练段 IR −0.279 / 验证段 −0.383）。

调查结论（代码级）：

| 组件 | 方向处理 | 结论 |
|---|---|---|
| 闸② | `|ICIR|`（docstring 明写「方向不约束，**方向与稳健性由闸④⑤把关**」） | ✅ |
| 闸③ | 置换检验（双尾） | ✅ |
| **闸④** | 池组合 = 各因子 zscore **无方向等权平均**（`_composite_ic`） | ❌ **方向盲** |
| 闸⑤ | `|ICIR_val| ≥ 0.3` **且** 两段 IC 均值同号（不管正负） | ✅ |
| 生产消费（选股 L2） | 权重 = `ic_mean_i / Σ|ic_mean_j|`（**带符号**），贡献 = 权重 × zscore | ✅ 负方向自动反向加权 |
| 衰减监控 | 触发条件 = 滚动 IC 连续为负 **且** `|ICIR| < 0.1` | ✅ 强负方向安全 |

即：**闸④评估的组合模型 ≠ 生产 L2 的组合模型**——裁判按「无方向池」判负数因子必然拖累
组合，而生产端（L2）本就用带符号 IC 权重、负方向因子可用。闸②把方向责任交给④⑤，⑤
把住了，④ 没把住（且与 spec 的「等权组合」表述并存着未声明的方向假设）。
后果：稳定负向且强度足够的因子（经济含义是可用的反转/过应信号）在入门前被系统性丢弃。

## What Changes

- **MODIFIED「五道闸准入管线」（factor-library）**：闸④池级组合增量的**组合口径**明确为
  **符号归一化等权组合**——组合内各因子（含候选）SHALL 按**训练段 RankIC 符号**定向后
  参与组合（符号不可定 → 该因子不参与组合；候选符号不可定 → 按原向参与，由 ②⑤ 兜底）。
  定向符号 SHALL 记入 `detail`（候选 `orientation`、池 `pool_orientations`）。
  统计门槛零改动：|ICIR| 0.3、BH-FDR q=0.1、冗余 |ρ| 0.7、⑤ 两段同号全部保持。
- **实现面**：`factors/validate.py::check_pool_increment`——池因子帧与候选帧按训练段符号
  定向后进 `_composite_ic`；detail 增审计字段。
- **不做**：不改 ②③⑤ 的任何门槛；不规范化库内表达式（方向由消费端带符号权重与监控
  符号条件处理——已实证兼容）；不引入验证段信息（定向只用训练段，随机因子的方向来自
  噪声、定向不改变其中位数，噪声拦截性质不变）。

## Capabilities

- **Modified Capabilities**: `factor-library`（五道闸准入管线，闸④组合口径）

## Impact

- 代码：`src/finance_agent/factors/validate.py`
- 测试：`tests/factors/test_validate.py`（负向候选定向通过 / 正向行为不变 / 方向不可定
  fail closed / 池因子定向 + 审计字段）
- 复跑证据：全量已拒候选重放（临时库）——两轮独立重放均入 **3 条**（`volratio20`/`volcv20`/
  `range1`，镜像定向受益者）；`max_ret_5d` 过②③后倒在**闸④冗余**（与 `range1` 的 IC 相关
  0.7008 > 0.7，同一信息簇只收一个代表）——闸门栈行为符合设计。
- **噪声安全性（如实声明）**：定向由**训练段**符号决定，对随机因子其中位数不变
  （review 蒙特卡洛 M=3000：旧 50.57% vs 新 50.23% 单闸通过率，差在抽样误差内；镜像增量
  精确相等）。但不回避一个真实效应：旧闸④的「验证段 IR > 0」实际充当了一个**单边方向过滤**，
  归一化后该过滤消失——孤立链（弱闸③、K=1）实测噪声入库率约 1.8×（25→45/79）；生产批次
  的 BH-FDR（K≈50-100）比该压力测试严格得多。此项列为**口径决策项**（如需恢复单边过滤
  强度，应显式调 ② 门槛，而不是靠④的副作用），不靠实现巧合维持安全边际。
