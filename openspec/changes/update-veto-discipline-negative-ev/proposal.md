# Proposal: update-veto-discipline-negative-ev

## Why

issue #625（P1 待拍板后的提案）：11-06 消融落地「否决纪律」后，方向否决被收窄到致命白名单——规则治好了「全中性锁死」（曾实证 judge 倾向 hold/watch 参与构成恒 watch），但留下一个反向缺口：**辩论内自算出的负期望不能否决方向**。

11-24 批实证（19 份有效决策全审计）：
- 000957 中通客车：保守方估算「止损先触 ~51% / 目标先触 ~19% / **名义期望约 −0.7%**」，risk_judge 写明「接受为真实风险」仅压仓位档位 → 维持 buy light，次日被 paper_execute 照单建仓。**缩仓只改变亏多少，不改变期望的正负号。**
- 对照：600938（赔率 1.25:1）与 920136（1.79:1）虽赔率低于 2:1 门槛，但按申报价与置信度估算期望非负（约 +0.3% / +1.5%）——这两例**不属本提案范围**，继续走「维持方向+缺口申报」（现行条款边界必须保留，防止规则回摆成「赔率不足即否决」）。

## What Changes

- risk_judge 否决纪律新增**负期望否决项**：辩论各方（含 risk_judge 自身）显式给出的触发概率与赔率估算加权期望为负时，risk_judge MUST NOT 在未尝试联合修正的情况下维持原方向，二选一：
  ① 联合修正（放宽止损至 ≥2×日波动或最近结构位、等比下调仓位档位）使期望非负后维持方向；
  ② 修正仍为负或不可行 → 降档 watch，`inaction_reason` MUST 指名「期望为负」的估算依据（触发概率/赔率/期望值数值与出处）。
- 边界固定：单一「赔率不足」而期望非负 → **仍不得否决方向**（现行条款原样保留）；期望输入 MUST 取辩论中已申报的概率与价位，MUST NOT 由 risk_judge 自造概率。
- trader 止损锚定条款**不变**。

## Capabilities

- **New Capabilities**: 无
- **Modified Capabilities**: agent-prompt-contracts（MODIFIED requirement「决策层否决纪律与参数协商」）

## Impact

- `src/finance_agent/prompts/risk_judge.md`：否决纪律段落新增负期望条款与边界（权威源改后必须 `uv run python scripts/deploy_prompts.py` 发布，否则 eval 门禁拒绝运行）
- 行为面：可能出现更多 watch——须以「期望为负且修正不可行」为唯一入口，且必须在理由里带数值；回归看点为 11-06 消融目标（不得回摆成普遍 watch）
- 评估：prompt 变更属「一次只动一个变量」，需独立批 + 历史决策离线回放抽验（000957 类样本应改判 watch；600938/920136 类应保持 buy）
- 交互类判别：不涉及前端/SSE/状态流转 → 不走 E2E 门禁；属评估约束范畴（历史决策回放 + 人工抽查）
