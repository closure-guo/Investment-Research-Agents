# Design: add-factor-direction-reversal-monitor

## Approach

入池定向符号的**单一来源**是闸④已计算的候选训练段 IC 符号（`_ic_stats(train_ic)[0]` 的符号）——本 delta 只做「落库 + 消费」，不新增计算路径。schema 变更限 `factors` 表加一列 `orientation INTEGER DEFAULT 0`；`admit_candidates` 在入库成功路径写入（与 `pool_increment` 落库同点）。

监控判据分支复用现有 `_decay_snapshot` 的滚动序列产物：`tail_means` 已算出，反转判据只需在其上比较 `sign(tail_means)` 与 `orientation`（全 20 点同号且与定向相反）。不加 ICIR 幅度门槛：滚动均值已是 60 日平滑，负向因子（典型日 IC std ~0.1、全史均值 ~-0.04）的 60 日滚动均值标准误约 std/√60 ≈ 0.013，连续 20 个滚动点为正需要持续的真实漂移，噪声穿越概率可忽略。

存量回填脚本：对每条因子取 `factor_ic` 全史均值符号（|均值| < 1e-12 或无样本 → 0）。幂等：仅当 `orientation IS NULL` 时写。

## Alternatives Considered

- **监控时用全史 IC 符号当定向（不落库）**：近期入库因子 IC 样本少、符号不稳；且「全史符号」随后验样本漂移，定向语义不稳定（同一因子今天的锚和下个月的锚不同）。落库把定向固定为入池时点事实，可审计。被否。
- **不降级、依赖打分侧 60 日滚动符号自适应跟转**：与准入语义冲突——跟转等于无准入地使用未经五道闸验证的方向（该方向从未做过单调性/样本外检验）；且因子继续占 active 桶位与结构查重域。被否。
- **反转判据加 |滚动 ICIR| ≥ 下限门槛（只降「强反转」）**：弱反转（均值翻正但 ICIR 弱）同样意味着入池依据失效 + 无信息，留在池里没有价值；且打分侧对其符号权重约等于噪声。选择无幅度门槛。

## Risks

- **误降级**（负向因子正常波动期被误判反转）：60 日滚动均值连续 20 日反向的噪声概率低（见上）；且 `degraded` 可经复核恢复 `active`（状态机既有通道），降级面损失有限。上线首月观察 `DIRECTION_REVERSAL` 触发频次，若出现误报再加幅度门槛（作为后续 delta，不改本契约）。
- **两判据同时命中的事件语义**：reason 取反转优先（方向失效是更强的失效形态），一条事件——spec 已定义，实现按序评估反转分支在前。
- **打分侧行为不变**：L2 权重仍按 60 日滚动 IC 符号；反转因子因离开 active 集合自然不再被打分消费（`list_active_factors` 过滤），无需改 ranker。
