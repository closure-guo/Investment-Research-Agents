# Proposal: update-price-check-exemption-tolerance

## Why

11-12 两例价位校验阻断（301220 主池批 `e6210fcf-843` / 605033 microcap 补跑批 `c9f86e2c-31d`）经 incident 026 纪律逐条人工终裁：四条 anomaly 全部为校验器侧缺口，零分析师真幻觉。本 delta 实施前对 301220 两轮 risk_judge 原始输出（Langfuse trace e1187b914f85…，round-1 35b1efab / round-2 b34cdcf7）做了校验器复现复核，**修正了 #592 原终裁的一处归因**：

- 301220 的 86%「文本价位 3」**不是**「2026Q3」的季度序号——半角 `Q3` 的 3 已被既有的「数字紧贴 ASCII 字母」规则（601818 M2 形态，10-08 落地）豁免，用两轮原文复跑当前校验器均归零；
- 真凶是 reasoning 的**编号列表记号 `3.` / `4.`**（「…余仓当日清空"\n3. "2026 年报或 2027Q1 单季毛利率…」）：`.` 不在 `_NON_PRICE_SUFFIX`、前邻 `"` 非 ASCII 字母，逃过全部守卫 → 归属布林下轨 21.4241、偏差 86.0%（round-1 的「4. 风险指标」同族、偏差 81.33%）。编号列表是模型结构化行文的固有形态，打回也删不掉 → 重试空转（incident 022 形状）。
- 20.67 系带边舍入（round-1 vs 近期低点 22.93 偏差 9.86%；round-2 vs 布林下轨 3.52%），带边吸附容差同时覆盖两轮。

不修则含编号列表行文 + 带边引用 + 倍数表述的正常决策会被持续阻断，且打回重试空转。

## What Changes

- **缺口 1（修正归因）——编号列表记号 `N.` 误报（301220 两轮实证）**：`_ENUM_SPAN_PATTERNS` 已豁免 `（3）`/`3)` 两形态，缺 `3.`（阿拉伯数字 + 西文句点 + 空白）列表形态。修法：`(?<![\d.])\d{1,2}\.(?=\s)` 入枚举排除区——记号后真实价位不受豁免（护栏钉死）；小数价位（`20.67`）与句末中文句号不受影响（lookbehind/lookahead 双守卫）。
- **缺口 2——× 量纲乘号误报（605033 round-1 实证，终裁归因维持）**：「约为 2×日波动以上」的 2 被提为价位、归属布林下轨 15.8963、偏差 87.42%。`_NON_PRICE_SUFFIX` 有「倍」无「×」。修法：× 入后缀豁免，与「倍」同策——× 后的数字不受豁免仍校验（护栏钉死）。
- **缺口 3——参考带边界舍入误报（301220 两轮实证，终裁归因维持）**：模型引用 context 自带 full_band 下沿 20.6714 按两位小数舍入写成 20.67，`_in_reference_bands` 判 `20.6714 <= 20.67` 为 False——比带边低 0.0014 即带外。修法：带边吸附容差（|值−带边| ≤ 最小报价量级 0.01 视为带内，上下沿对称）——容差外的真实带边价位仍阻断（护栏钉死）。
- **Q\d 季度记号：不改**。原 #592 归因（Q3 季度序号）经原文复现证伪——半角形态已被 ASCII 前缀规则覆盖；全角 `Ｑ3` 形态无生产证据，按本族「豁免须有生产实证」纪律不加投机豁免（探测脚本留档于本 delta proposal）。
