## 核验方法

资格判定链：`selection_pool` = L3 `keep` ∩ `days_in_top_recent(symbol, as_of, mode=当日 selection_mode) ≥ DEFAULT_MIN_DAYS(3)`，窗口 `STABILITY_WINDOW_DAYS = 5`。

在 backend 容器内（热库在卷里，宿主 `data/` 为回滚副本禁直读）用只读 SQL 独立复算两个口径，再与当日**实际落库**的 `selection_pool` 行逐只比对：

| 口径 | 轴定义 | 含义 |
|---|---|---|
| **A 同模式轴** | `l2_candidates` DISTINCT trade_date ≤ as_of，LEFT JOIN `screening_batches`，只保留 `selection_mode = 当日模式`（或批次行缺失）的日子，取最近 5 个 | PR #500 修复后的正确口径 |
| **B 混合轴** | `l2_candidates` DISTINCT trade_date ≤ as_of，不分模式，取最近 5 个 | 修复前日批路径的实际退化口径（缺陷） |

判定：`actual == A` 即口径一致；两轴不同的日子才具判别力（`A ≠ B` 时 actual 落在哪边说明哪套口径在生效）。

复算结果与生产函数 `store.days_in_top_recent(..., mode=MODE)` 对 11-02 全部 99 只 keep 标的逐只交叉核对：**0 不一致**。

## 异常记录

无失败项。两条备注：

1. 辅助脚本的轴日期标签取模式首字母 `(f)`，factor / fallback 撞字——仅展示歧义，判定 SQL 用完整 `selection_mode` 字符串，本报告轴列已按 `screening_batches` 原值标注 fb。
2. `update-stability-gate-rolling-window/tasks.md` 的待验项写的是「观察 **11-02** 因子模式恢复日：池子不清零」，但生产实际恢复日是 **10-26**（10-21~10-23 fallback → 10-26 factor）。观察到的轨迹：10-26 池 2 → 10-27 池 2 → 10-28 池 16 → 10-29 池 25 → 10-30 池 35 → 11-02 池 33。10-26/10-27 的「池 2」不是清零而是同模式历史稀疏（同模式轴仅 3~4 个 factor 日可用）+ 混合轴缺陷叠加；修复后未再出现任何 factor 日清零。该待验项的前提日期已漂移，勾选时建议在 tasks.md 该行追加备注「实际恢复日 10-26，轨迹见本报告」。

## 附录：复算核心逻辑（容器内只读执行）

```python
from finance_agent.screening import store as S
conn = S._connect(None)                     # 生产默认库路径
MODE = 当日 screening_batches.selection_mode
same_axis = [...]  # SELECT DISTINCT c.trade_date FROM l2_candidates c
                   #   LEFT JOIN screening_batches b ON b.trade_date=c.trade_date AND b.pool=c.pool
                   #   WHERE c.trade_date<=? AND c.pool='main'
                   #   AND (b.selection_mode IS NULL OR b.selection_mode=?) ORDER BY DESC LIMIT 5
mixed_axis = [...] # SELECT DISTINCT trade_date FROM l2_candidates WHERE trade_date<=? AND pool='main'
                   #   ORDER BY DESC LIMIT 5
hits(sym, axis) = 0 if sym ∉ l2(as_of) else |{d ∈ axis : sym ∈ l2(d)}|
A = {s ∈ keep : hits(s, same_axis) ≥ 3};  B = {s ∈ keep : hits(s, mixed_axis) ≥ 3}
assert hits(s, same_axis) == S.days_in_top_recent(s, as_of, pool='main', mode=MODE)  # 99/99 ✓
compare A / B / set(selection_pool rows)
```

执行方式：`docker compose exec -T backend python - < <脚本>`（stdin 管道，避免 MSYS 路径改写；全程 SELECT，无写入，无重启）。
